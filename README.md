# 云书库（Flask + MySQL）

一个局域网文件浏览/阅读/管理应用：运行后直接进入主页面，无需登录；支持浏览、查看、播放、下载、上传、搜索、标签、游戏等功能。

## 技术栈

- Python 3.11+（本项目以 3.11 开发验证）
- Flask 3.x
- MySQL 8.0（使用 `pymysql` 驱动）
- markdown（把 Markdown 文档与代码文件渲染成网页）
- bleach（对 Markdown 渲染产物做白名单过滤，防存储型 XSS；markdown 默认保留文件内原始 HTML）
- Pillow（为图片生成压缩缩略图；未安装时图片缩略图返回 404，卡片退用原图，不影响其它功能）
- python-docx / openpyxl / xlrd（docx / xlsx / xls 在线预览解析；未安装时对应格式显示"不可预览"，不影响其它功能）
- imageio-ffmpeg（自带 ffmpeg 二进制，为视频生成封面缩略图、探测时长、兼容转码；未安装时缩略图/时长返回 404，不影响其它功能）

> 模块划分原则：**三层分层，不同功能分到不同模块，一个模块只做一件事**。
> - `blueprints/`（路由层）：每个功能一个蓝图——浏览、查看、媒体、下载、管理、游戏、回收站、标签、统计各自独立，只处理 HTTP 交互；
> - `services/`（纯逻辑层）：不依赖 Flask，按职责拆成单用途模块——`path_utils`（路径安全）、`dir_utils`（目录操作）、`text_utils`（文本/文档）、`media_utils`（视频抽帧/转码/时长、图片缩略图）、`office_utils`（Office 解析）、`trash_utils`（回收站）、`file_ops`（移动/复制/批量）、`game_utils`（游戏卸载）、`stats_utils`（磁盘统计）、`tag_store`（标签读写）；
> - `static/`（前端资源）：公共 CSS 与主题 JS 抽取为 `common.css` / `theme.js`，各模板只保留页面特有样式，避免重复粘贴。

## 运行步骤

### 1. 安装依赖

```bash
pip install flask pymysql markdown bleach imageio-ffmpeg pillow python-docx openpyxl xlrd
```

### 2. 数据库配置（可选）

[db.py](db.py) 会自动适配本机 MySQL，一般无需改动：

- 用户名：默认 `root`，可用环境变量 `DB_USER` 覆盖；
- 密码：优先读环境变量 `DB_PASSWORD`，未设置时自动在常见候选密码中探测可用项并缓存；
- 库名：`login_db`（见 `DB_NAME`，首次运行自动创建）。

如需显式指定，可临时设置环境变量后启动：

```powershell
$env:DB_USER="root"; $env:DB_PASSWORD="你的密码"; python app.py
```

### 3. 初始化数据库

首次运行前执行（会创建 `login_db` 库与标签表，可重复执行）：

```bash
python db.py
```

### 4. 启动应用

```bash
python app.py
```

> 内容浏览根目录默认为项目内 `text/`。如需浏览本机其它目录（如个人内容盘），
> 启动前设置环境变量即可：`$env:TEXT_DIR="F:\某目录"; python app.py`。

启动后浏览器访问：

- 本机：<http://127.0.0.1:5000>
- 局域网其他设备：`http://<本机IP>:5000`（需放行防火墙 TCP 5000 端口，如 `New-NetFirewallRule -DisplayName 'Flask App 5000' -Direction Inbound -Protocol TCP -LocalPort 5000 -Action Allow -Profile Any`）

> 无需登录，启动后访问任意地址（`/`、`/browse/...` 等）直接进入对应页面。

## 数据库说明

| 项目 | 说明 |
| --- | --- |
| 数据库名 | `login_db` |
| 表 `tags` | 文件标签：`id`（自增主键）、`name`（唯一）、`created_at` |
| 表 `file_tags` | 标签×文件多对多：`id`、`tag_id`（外键，删除标签时级联删除）、`path`（相对路径）、`path_md5`（路径 md5 索引）、`created_at`，`(tag_id, path_md5)` 唯一保证同文件同标签只打一次 |

文件标签读写统一经 `services/tag_store`，表结构见 [db.py](db.py) 的 `init_db()`。

## 关键接口

> 完整、详细的接口文档（含参数、返回、权限、错误码与二次开发指引）见 [API.md](API.md)。下表为速查。

| 路由 | 方法 | 说明 |
| --- | --- | --- |
| `/` | GET | 主页，浏览 `text/` 根目录 |
| `/browse/<path>` | GET | 浏览指定文件夹，文件夹/文件均以卡片网格展示 |
| `/view/<path>` | GET | 查看指定文档/图片/PDF/视频内容 |
| `/media/<path>` | GET | 以二进制流返回图片/PDF/视频/音频内容（支持 Range；视频由查看页自定义播放器加载，音频由浏览器原生播放） |
| `/game` | GET | 游戏大厅，列出 game/ 下所有含 index.html 的游戏 |
| `/game/<path>` | GET | 返回游戏目录内静态文件（index.html 等），供新标签页游玩（防目录穿越） |
| `/game/uninstall/<name>` | POST | 卸载游戏：软删除移入 `_removed_games/`（可还原） |
| `/game/uninstalled` | GET | 已卸载游戏列表页（可还原 / 彻底删除） |
| `/game/restore/<name>` | POST | 还原已卸载游戏回游戏大厅 |
| `/game/purge/<name>` | POST | 彻底删除已卸载游戏（物理删除，不可恢复） |
| `/thumb/<path>` | GET | 返回视频封面缩略图（JPG，首次抽帧后缓存） |
| `/imgthumb/<path>` | GET | 返回图片压缩缩略图（JPG，Pillow 缩放缓存） |
| `/duration/<path>` | GET | 返回视频时长 JSON `{"duration": 秒\|null}`（文件卡片角标用） |
| `/download/<path>` | GET | 下载：单个文件原样返回；目录打包成 zip |
| `/search?q=关键字&path=起始目录&mode=name\|content` | GET | 递归搜索：`mode=name` 按文件名、`mode=content` 按文件内容（带上下文摘要），path 缺省从根目录搜起；q 为空则跳回起始目录 |
| `/upload/`、`/upload/<path>` | POST | 上传多个文件到根目录 / 指定目录（`enctype=multipart/form-data`，字段名 `files`） |
| `/mkdir/`、`/mkdir/<path>` | POST | 在当前目录新建文件夹（表单字段 `new_folder`） |
| `/rename/<path>` | POST | 重命名文件或目录（表单字段 `new_name`，拒绝含路径分隔符或重名） |
| `/delete/<path>` | POST | 软删除文件或目录（移入回收站，可还原） |
| `/edit/<path>` | GET | 打开在线文本编辑器（仅文本类扩展名） |
| `/save/<path>` | POST | 保存编辑器内容（表单字段 `content`，统一转 UTF-8 写回；成功跳回编辑页） |
| `/move/<path>` | POST | 移动文件/目录到目标目录（表单字段 `dest_subpath`；目标重名自动改名） |
| `/copy/<path>` | POST | 复制文件/目录到目标目录（表单字段 `dest_subpath`） |
| `/batch_move/` | POST | 批量移动：表单 `paths`（可多个）+ `dest_subpath`，返回 `{ok, succeed, failed, errors}` |
| `/batch_copy/` | POST | 批量复制：表单 `paths` + `dest_subpath`，返回 `{ok, succeed, failed, errors}` |
| `/batch_delete/` | POST | 批量软删除：表单 `paths`（可多个），移入回收站，返回 `{ok, succeed, failed, errors}` |
| `/trash` | GET | 回收站列表页 |
| `/trash/restore/<name>` | POST | 还原回收站条目到原位置（原位置被占返回 409） |
| `/trash/delete/<name>` | POST | 彻底删除单个回收站条目（物理删除，不可恢复） |
| `/trash/empty` | POST | 清空回收站（全部物理删除） |
| `/tags` | GET | 标签管理页（全部标签 + 使用次数） |
| `/tags/filter?tag=名称` | GET | 按标签筛选，展示打该标签的全部文件/目录 |
| `/tag/get?path=...` | GET | 查询某路径当前全部标签，返回 JSON |
| `/tag/set` | POST | 打标签（整体替换）：表单 `path` + `tags`（逗号分隔，可空=清空） |
| `/tag/remove` | POST | 取消标签：表单 `path` + `tag` |
| `/tag/delete` | POST | 删除整个标签（连带清掉所有文件上的该标签） |
| `/stats` | GET | 磁盘占用统计页（按文件类型 / 目录条形图） |
