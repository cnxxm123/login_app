# Scrapy 框架 详解

## 一、Scrapy 是什么？

**Scrapy** 是一个用 Python 编写的、功能强大的**爬虫框架**。它把爬虫的通用流程（调度、请求、下载、解析、存储、去重、中间件）都封装好了，我们只需要编写核心的"爬虫逻辑"，就能高效抓取大规模数据。

### 安装

```bash
pip install scrapy
```

### Scrapy 架构（组件与数据流）

```
            ┌─────────────┐
            │   Scheduler  │  调度器（管理请求队列，去重）
            └──────┬──────┘
                   │ 请求
        ┌──────────▼──────────┐
        │       引擎 Engine    │  核心，控制数据流转
        └──┬───────────┬──────┘
  请求     │           │ 响应
┌──────────▼────┐    ┌─▼──────────────┐
│ 下载器 Downloader│◄──►│ 爬虫 Spider      │  解析页面、yield 请求/数据
└────────────────┘    └─┬──────────────┘
                        │ item
                  ┌─────▼─────┐
                  │ 管道 Pipeline │  数据清洗、存储
                  └───────────┘

 另外：下载器中间件（Downloader Middleware）、爬虫中间件（Spider Middleware）
     负责对请求/响应做预处理（UA、代理、加解密）
```

**数据流简要**：

1. Spider 产出初始请求 → 引擎 → 调度器；
2. 调度器排出请求 → 引擎 → 下载器中间件 → 下载器发请求；
3. 下载器返回响应 → 引擎 → Spider 的 `parse` 解析；
4. Spider 产出 item 或新的请求（item 进管道存储，请求回调度器继续）。

## 三、settings 常用配置

| 配置项 | 作用 | 示例 |
| ------ | ---- | ---- |
| `ROBOTSTXT_OBEY` | 是否遵守 robots 协议 | `ROBOTSTXT_OBEY = False`（爬虫一般关掉） |

## 四、编写 Spider

### 1. 基本 Spider

```python
import scrapy


class MySpider(scrapy.Spider):
    name = "myspider"                       # 爬虫唯一标识
    allowed_domains = ["4399.com"]          # 允许的域名（出域请求被过滤）
    start_urls = ["https://4399.com"]       # 起始 URL

    def parse(self, response, **kwargs):
        # response 是响应对象，可以用 xpath / css 提取数据
        title = response.xpath("//title/text()").get()
        yield {"title": title}              # yield 字典 / Item / Request
```

### 2. yield 一个请求（翻页/进详情）

```python
import scrapy


class MySpider(scrapy.Spider):
    name = "myspider"
    start_urls = ["https://example.com/list"]

    def parse(self, response, **kwargs):
        hrefs = response.xpath("//a/@href").getall()
        for href in hrefs:
            # 拼接完整 URL
            new_url = response.urljoin(href)
            # 发起新请求
            yield scrapy.Request(
                url=new_url,
                method="get",
                dont_filter=True,                  # 不去重（默认按 URL 去重）
                meta={"path": "./img"},            # 传递数据给回调（万能行李舱）
                callback=self.parse_detail,        # 指定回调函数
            )

    def parse_detail(self, response, **kwargs):
        # 用 meta 取出上一个请求传过来的数据
        print(response.meta["path"])
        yield {"url": response.url}
```

### 3. 重写 start_requests

有时需要自定义起始请求（比如带 cookie、POST 等）：

```python
import scrapy


class MySpider(scrapy.Spider):
    name = "my_spyder"
    allowed_domains = ["4399.com"]
    start_urls = ["https://4399.com"]

    def start_requests(self):
        for url in self.start_urls:
            yield scrapy.Request(url=url, dont_filter=True, callback=self.parse)
```

### 4. 发送带 query-string 的请求

注意：**Scrapy 不会像 requests 那样自动拼接参数，需要手动拼接**。

```python
import scrapy
import urllib.parse


class PostWithQsSpider(scrapy.Spider):
    name = "post_qs"
    allowed_domains = ["httpbin.org"]
    start_urls = ["https://httpbin.org"]

    def start_requests(self):
        # 1. 查询参数放字典
        qs_dict = {"page": 3, "size": 10, "sort": "desc"}
        # 2. 编码成 query-string
        qs = urllib.parse.urlencode(qs_dict)      # page=3&size=10&sort=desc
        url = f"https://httpbin.org/get?{qs}"
        yield scrapy.Request(url=url, method="GET", callback=self.parse)

    def parse(self, response, **kwargs):
        j = response.json()       # response.json() 解析 JSON
        yield j
```

### 5. 提交表单（FormRequest）

`FormRequest` 是 `Request` 的子类，专门用于模拟 HTML 表单提交：

```python
import scrapy


class LoginSpider(scrapy.Spider):
    name = "login"
    start_urls = ["https://example.com/login"]

    def parse(self, response, **kwargs):
        yield scrapy.FormRequest(
            url="https://example.com/login",
            formdata={"username": "alex", "password": "123456"},  # 表单字段
            callback=self.after_login,
        )

    def after_login(self, response, **kwargs):
        yield {"登录结果页面": response.text[:200]}
```

### 6. 定义 Item（规范数据结构）

在 `items.py` 中定义字段，让数据结构更清晰，Pipeline 处理也更方便：

```python
import scrapy


class TianyaItem(scrapy.Item):
    title = scrapy.Field()      # 标题
    author = scrapy.Field()     # 作者
    content = scrapy.Field()    # 内容
    url = scrapy.Field()        # 链接
```

Spider 中使用：

```python
from tianya.items import TianyaItem

def parse_detail(self, response, **kwargs):
    item = TianyaItem()
    item["title"] = response.xpath("//h1/text()").get()
    item["url"] = response.url
    return item     # 或 yield item
```

> Item 本质上是一个带校验的字典：只能使用已定义的字段，未定义的字段会报错。不追求规范时直接 `yield` 字典也可以。

### 7. 选择器取值技巧（高频考点）

| 方法 | 作用 | 没有匹配时 |
| ---- | ---- | ---------- |
| `.get()` | 取第一个（新版推荐） | 返回 `None` |
| `.getall()` | 取全部，返回 list（新版推荐） | 返回 `[]` |
| `.extract_first()` | 取第一个（旧版） | 返回 `None` |
| `.extract()` | 取全部，返回 list（旧版） | 返回 `[]` |

```python
title = response.xpath("//title/text()").get()          # str 或 None
hrefs = response.xpath("//a/@href").getall()            # list
first = response.css("a::attr(href)").get()             # css 同理
```

> 老教程多用 `extract/extract_first`，新版本两者都可用，功能完全相同，建议统一用 `get/getall`。

### 8. 日志输出（spider.logger）

```python
import scrapy


class MySpider(scrapy.Spider):
    name = "myspider"

    def parse(self, response, **kwargs):
        self.logger.info("正在解析: %s", response.url)     # 普通信息
        self.logger.warning("注意: %s", response.status)   # 警告
        self.logger.error("出错: %s", response.status)     # 错误
```

> 用 `spider.logger` 打印比 `print` 更专业：会自动带上爬虫名、时间、等级，且能通过 `LOG_LEVEL` 控制是否显示。

## 五、Pipeline 管道（数据存储）

管道负责对 Spider 产出的 item 进行清洗和存储。多个管道按 settings 中的数字从小到大依次执行。

### 1. 文本文件写入

**错误做法**：在 `process_item` 里每次 `open` 文件，有多少数据开多少次文件，不优雅。

**正确做法**：用 `open_spider`（爬虫开始时执行一次）打开文件，`close_spider`（结束时执行一次）关闭文件。

```python
class CaipiaoFilePipeline:

    def open_spider(self, spider):
        # 爬虫开始时执行一次
        self.f = open("caipiao.csv", mode="a", encoding="utf-8")

    def close_spider(self, spider):
        # 爬虫结束时执行一次
        if self.f:
            self.f.close()

    def process_item(self, item, spider):
        # 每条数据都会走到这里
        self.f.write(f"{item['qihao']}, {'_'.join(item['red_ball'])}, {'_'.join(item['blue_ball'])}\n")
        return item    # 返回 item 继续交给下一个管道
```

**别忘了在 settings 注册管道**：

```python
ITEM_PIPELINES = {
    'caipiao.pipelines.CaipiaoFilePipeline': 300,   # 数字越小离引擎越近，越先执行
}
```

先在 settings 中配置数据库信息：

管道中创建/关闭连接、逐条保存：

```python
import pymysql
from caipiao.settings import MYSQL_CONFIG as mysql


class CaipiaoMySQLPipeline:

    def open_spider(self, spider):
        self.conn = pymysql.connect(
            host=mysql["host"], port=mysql["port"],
            user=mysql["user"], password=mysql["password"],
            database=mysql["database"],
        )

    def close_spider(self, spider):
        self.conn.close()

    def process_item(self, item, spider):
        try:
            cursor = self.conn.cursor()
            sql = "insert into caipiao(qihao, red, blue) values(%s, %s, %s)"
            red = ",".join(item["red_ball"])
            blue = ",".join(item["blue_ball"])
            cursor.execute(sql, (item["qihao"], red, blue))   # 参数化防注入
            self.conn.commit()
            spider.logger.info(f"保存数据{item}")
        except Exception as e:
            self.conn.rollback()
            spider.logger.error(f"保存数据库失败! {e}, 数据: {item}")
        return item
```

### 4. 图片/文件自动下载（ImagesPipeline / FilesPipeline）

- **图片**：使用 `ImagesPipeline`；
- **其他文件**（pdf/doc/zip/视频音频等）：使用 `FilesPipeline`。

三个核心方法：

| 方法 | 作用 |
| ---- | ---- |
| `get_media_requests(item, info)` | yield 出图片/文件的下载请求 |
| `file_path(request, response, info, item)` | 返回保存路径 |
| `item_completed(results, item, info)` | 收尾工作，返回 item 给下一个管道 |

```python
import scrapy


class PitcherSpider(scrapy.Spider):
    name = "pitcher"
    start_urls = ["https://www.example.com"]

    def parse(self, response, **kwargs):
        hrefs = response.xpath("//div[@class='t']/a/@href").extract()
        for href in hrefs:
            yield scrapy.Request(response.urljoin(href), callback=self.download)

    def download(self, response, **kwargs):
        img_src = response.xpath("//ul[@class='adw']/li/img/@src").extract()
        yield img_src
```

```python
from scrapy import Request
from scrapy.pipelines.images import ImagesPipeline


class TuPianPipeline_Pitcher(ImagesPipeline):
    # 1. 生成下载请求
    def get_media_requests(self, item, info):
        for url in item:                       # item 是一堆图片地址
            yield Request(url, meta={"url": url})

    # 2. 返回保存路径
    def file_path(self, request, response, info, item):
        name = request.meta["url"].split("/")[-1]
        return f"pictures/{name}"

    # 3. 收尾
    def item_completed(self, results, item, info):
        return item
```

settings 配置：

```python
ITEM_PIPELINES = {
```

## 六、中间件（AOP 面向切面编程）

中间件的作用：在**请求发送前**和**响应返回后**对请求/响应做预处理。这样我们就不用把 UA、代理、加解密等逻辑写进 Spider 里，代码更干净。

### 1. Downloader Middleware（下载器中间件，最常用）

```python
class MidDownloaderMiddleware1:

    def process_request(self, request, spider):
        # 每个请求到达下载器之前调用
        print("process_request", "ware1")
        return None

    def process_response(self, request, response, spider):
        # 每个请求从下载器返回后调用
        print("process_response", "ware1")
        return response

    def process_exception(self, request, exception, spider):
        # 请求发生异常时调用
        print("process_exception", "ware1")


class MidDownloaderMiddleware2:

    @classmethod
    def from_crawler(cls, crawler):
        # Scrapy 通过这个类方法创建中间件对象
        s = cls()
        crawler.signals.connect(s.spider_opened, signal=signals.spider_opened)
        crawler.signals.connect(s.over, signal=signals.spider_closed)
        return s

    def process_request(self, request, spider):
        return None

    def process_response(self, request, response, spider):
        return response

    def process_exception(self, request, exception, spider):
        pass

    def spider_opened(self, spider):
        print("爬虫开始")

    def over(self):
        print("爬虫结束")
```

**注册中间件**：

```python
DOWNLOADER_MIDDLEWARES = {
    'mid.middlewares.MidDownloaderMiddleware1': 543,   # 数字越小越先执行 process_request
    'mid.middlewares.MidDownloaderMiddleware2': 544,
}
```

**三个方法的返回值（难点，务必理解）**：

**process_request 返回值**：

| 返回值 | 效果 |
| ------ | ---- |
| `return None` | 不拦截，请求继续向后传（给下一个中间件或下载器） |
| `return Request` | 拦截并替换请求，后续中间件/下载器收不到原请求 |
| `return Response` | 拦截，直接返回响应，下载器不会发请求 |

**process_response 返回值**：

| 返回值 | 效果 |
| ------ | ---- |
| `return Response` | 响应继续向后传（给下一个 process_response 或 Spider） |
| `return Request` | 响应被拦截，请求直接回到调度器重新入队 |

### 3. 中间件实战：代理 IP

**免费代理**（随机选择，失败重试）：

```python
from random import choice
from mid.settings import PROXY_LIST


class ProxyMiddleware:

    def process_request(self, request, spider):
        proxy = choice(PROXY_LIST)
        request.meta["proxy"] = "https://" + proxy    # 设置代理
        return None

    def process_response(self, request, response, spider):
        if response.status != 200:
            print("尝试失败，重新请求")
            request.dont_filter = True    # 丢回调度器重新请求
            return request
        return response

    def process_exception(self, request, exception, spider):
        print("出错了:", exception)
```

**收费代理（隧道代理）**：

```python
class MoneyProxyMiddleware:

    def _get_proxy(self):
        # 以快代理隧道代理为例
        url = "http://tps138.kdlapi.com:15818"
        auth = basic_auth_header(username="你的用户名", password="你的密码")
        return url, auth

    def process_request(self, request, spider):
        url, auth = self._get_proxy()
        request.meta["proxy"] = url
        request.headers["Proxy-Authorization"] = auth
        request.headers["Connection"] = "close"
        return None

    def process_response(self, request, response, spider):
        if response.status != 200:
            request.dont_filter = True
            return request
        return response

    def process_exception(self, request, exception, spider):
        pass
```

### 4. Spider Middleware（爬虫中间件，了解）

位于引擎和 Spider 之间，常用方法：

```python
class CuowuSpiderMiddleware:

    @classmethod
    def from_crawler(cls, crawler):
        s = cls()
        crawler.signals.connect(s.spider_opened, signal=signals.spider_opened)
        return s

    def process_spider_input(self, response, spider):
        # 响应即将进入 Spider 时调用；返回 None 或抛异常
        return None

    def process_spider_output(self, response, result, spider):
        # Spider 产出数据后调用；必须 yield item 或 request
        for i in result:
            yield i

    def process_spider_exception(self, response, exception, spider):
        # Spider 中报错时调用；可 yield item 或 request
        pass

    def process_start_requests(self, start_requests, spider):
        # 爬虫启动时调用；必须只返回 request
        for r in start_requests:
            yield r

    def spider_opened(self, spider):
        pass
```

## 七、全站爬取

### 1. 使用普通 Spider + LinkExtractor

**LinkExtractor（链接提取器）**：从响应页面中按规则提取 URL，非常方便。

常用参数：

| 参数 | 说明 |
| ---- | ---- |
| `allow` | 正则列表，只提取匹配的链接 |
| `deny` | 正则列表，剔除匹配的链接 |
| `allow_domains` | 只提取这些域名的链接 |
| `deny_domains` | 剔除这些域名的链接 |
| `restrict_xpaths` | 只在符合 xpath 的区域内提取 |
| `restrict_css` | 只在符合 css 选择器的区域内提取 |
| `tags` | 从哪些标签提取（默认 a, area） |
| `attrs` | 从哪个属性提取（默认 href） |

```python
import scrapy
from scrapy.linkextractors import LinkExtractor


class ErshouSpider(scrapy.Spider):
    name = "ershou"
    allowed_domains = ["che168.com"]
    start_urls = ["https://www.che168.com/china/a0_0msdgscncgpi1ltocsp1exx0/"]

    def parse(self, resp, **kwargs):
        # 提取详情页链接
        le = LinkExtractor(
            restrict_xpaths=("//ul[@class='viewlist_ul']/li/a",),
            deny_domains=("topicm.che168.com",),
        )
        for link in le.extract_links(resp):
            yield scrapy.Request(url=link.url, callback=self.parse_detail)

        # 翻页
        le2 = LinkExtractor(restrict_xpaths=("//div[@id='listpagination']/a",))
        for page in le2.extract_links(resp):
            yield scrapy.Request(url=page.url, callback=self.parse)

    def parse_detail(self, resp, **kwargs):
        title = resp.xpath("/html/body/div[5]/div[2]/h3/text()").extract_first()
        print(title)
```

> **注意**：提取到的 URL 会有重复，但不用管——**Scrapy 的调度器会自动去重**。

### 2. 使用 CrawlSpider（更省事）

创建 CrawlSpider（注意加 `-t crawl` 模板）：

```bash
scrapy startproject qichezhijia
cd qichezhijia
scrapy genspider -t crawl ershouche che168.com
```

通过 `rules` 自动提取链接：

```python
import scrapy
from scrapy.spiders import CrawlSpider, Rule
from scrapy.linkextractors import LinkExtractor


class ErshoucheSpider(CrawlSpider):
    name = "ershouche"
    allowed_domains = ["che168.com", "autohome.com.cn"]
    start_urls = ["https://www.che168.com/beijing/a0_0msdgscncgpi1ltocsp1exx0/"]

    le = LinkExtractor(restrict_xpaths=("//ul[@class='viewlist_ul']/li/a",),
                       deny_domains=("topicm.che168.com",))
    le1 = LinkExtractor(restrict_xpaths=("//div[@id='listpagination']/a",))

    rules = (
        Rule(le1, follow=True),            # 翻页：提取链接并继续 follow
        Rule(le, callback="parse_item", follow=False),   # 详情：交给回调解析
    )

    def parse_item(self, response, **kwargs):
        print(response.url)
```

**CrawlSpider 工作流程**：请求返回后，自动按 `rules` 提取链接；`follow=True` 表示继续在下一页提取（相当于手动 `callback=self.parse`），`callback` 指定的函数处理数据页。

## 八、增量式爬虫

**思想**：把爬取过的 URL 存到 Redis 中，下次爬取时对比，已经抓过的就不再抓。

```python
import scrapy
from redis import Redis
from tianya.items import TianyaItem


class TySpider(scrapy.Spider):
    name = "ty"
    allowed_domains = ["tianya.cn"]
    start_urls = ["http://bbs.tianya.cn/list-worldlook-1.shtml"]

    def __init__(self, name=None, **kwargs):
        self.red = Redis(password="123456", db=6, decode_responses=True)
        super().__init__(name, **kwargs)

    def parse(self, resp, **kwargs):
        tbodys = resp.css(".tab-bbs-list tbody")[1:]
        for tbody in tbodys:
            hrefs = tbody.xpath("./tr/td[1]/a/@href").extract()
            for h in hrefs:
                url = resp.urljoin(h)
                # 1. URL 去重：判断是否在 Redis set 中
                if not self.red.sismember("tianya:details", url):
                    yield scrapy.Request(url=url, callback=self.parse_details)
                else:
                    print(f"该 url 已经被抓取过 {url}")

        # 翻页
        next_href = resp.xpath(
            "//div[@class='short-pages-2 clearfix']/div[@class='links']/a[last()]/@href"
        ).extract_first()
        yield scrapy.Request(url=resp.urljoin(next_href), callback=self.parse)

    def parse_details(self, resp, **kwargs):
        title = resp.xpath('//*[@id="post_head"]/h1/span[1]/span/text()').extract_first()
        content = resp.xpath('//*[@id="bd"]/div[4]/div[1]/div/div[2]/div[1]/text()').extract_first()
        item = TianyaItem()
        item["title"] = title
        item["content"] = content
        # 抓取完把 URL 加入 Redis
        self.red.sadd("tianya:details", resp.url)
        return item
```

管道中做**数据内容去重**（二次保险）：

```python
import json
from redis import Redis


class TianyaPipeline:

    def open_spider(self, spider):
        self.red = Redis(password="123456", db=6, decode_responses=True)

    def close_spider(self, spider):
        self.red.close()

    def process_item(self, item, spider):
        # 2. 内容去重：根据数据指纹判断是否存过
        r = self.red.sadd("tianya:pipelines:items", json.dumps(dict(item)))
        if r:
            print("存入数据库", item["title"])
        else:
            print("已经在数据里了", item["title"])
        return item
```

**两种去重方案对比**：

| 方案 | 优点 | 缺点 |
| ---- | ---- | ---- |
| URL 去重（sismember） | 简单高效 | 帖子有回复时无法抓到最新内容 |
| 内容去重（数据指纹） | 数据一致性好 | 每次都要先解析出内容才能判断 |

## 九、分布式爬虫（scrapy-redis）

分布式 = 多台机器/多个爬虫同时抓取。核心问题：**多个爬虫如何共享请求队列和去重集合？** —— 用 Redis 作为共享调度器。

```bash
pip install scrapy-redis==0.9.1
```

### 工作流程

1. 爬虫从 `redis_key` 获取起始 URL，放入 Redis 请求队列；
2. 任一个节点产生新请求，都在 Redis 的去重集合中判断是否抓过；
3. 抓过就放弃，没抓过就丢进 Redis 请求队列；
4. 调度器从队列取请求分发给各节点。

### 改造步骤

**1. Spider 继承 RedisSpider，用 redis_key 代替 start_urls**：

```python
from scrapy_redis.spiders import RedisSpider


class ShuSpider(RedisSpider):
    name = "shu"
    redis_key = "shu:start_urls"   # 起始 URL 由外部写入 Redis

    def parse(self, response, **kwargs):
        ...
```

**2. settings 配置 Redis 与 scrapy-redis**：

```python
REDIS_HOST = "127.0.0.1"
REDIS_PORT = 6379
REDIS_DB = 8
REDIS_PARAMS = {"password": "123456"}

# scrapy-redis 固定配置
SCHEDULER = "scrapy_redis.scheduler.Scheduler"
SCHEDULER_PERSIST = True   # 关闭时保存请求信息（中断可续爬）
DUPEFILTER_CLASS = "scrapy_redis.dupefilter.RFPDupeFilter"   # 用 Redis 去重

ITEM_PIPELINES = {
    "shu.pipelines.ShuPipeline": 300,
    "scrapy_redis.pipelines.RedisPipeline": 301,   # Redis 统一保存数据
}
```

**3. 向 Redis 推送起始 URL**：

```bash
redis-cli
> lpush shu:start_urls "https://www.example.com/book/1"
```

## 十、反爬设置汇总

### 1. User-Agent

- 统一 UA：settings 里 `USER_AGENT = '...'`；
- 动态 UA：settings 定义 `USER_AGENT_LIST`，中间件随机选择（见上文）。

### 2. Cookie

- **关闭 cookie 中间件（不推荐）**：会把 headers 里的 cookie 干掉，且不再自动管理 cookie；
- **开启 cookie 中间件（推荐）**：默认开启。在 `start_requests` 中给 `scrapy.Request` 传 `cookies` 字典，中间件自动管理：

```python
def start_requests(self):
    headers = {"User-Agent": "Mozilla/5.0 ..."}
    cookies = {
        "uuid": "66a0f5e7546b4e068497.1542881406.1.0.0",
        "_lxsdk_cuid": "1673ae5bfd3c8-0ab24c91d32ccc8-143d7240-144000-1673ae5bfd4c8",
    }
    yield scrapy.Request(
        url="https://example.com/detail",
        headers=headers,
        cookies=cookies,
        callback=self.detail_parse,
        meta={"myItem": item},
        dont_filter=True,
    )
```

同时设置 `ROBOTSTXT_OBEY = False`。

### 3. Referer（防盗链）

图片、视频等资源常校验 `Referer` 头，需在请求头中带上来源页面地址。

### 4. 代理 IP

在中间件中设置 `request.meta["proxy"]`（见上文"中间件实战：代理 IP"）。

## 十一、Request / FormRequest / Response 速查

### Request 参数

```python
scrapy.Request(
    url,                    # 字符串，唯一必填
    callback=None,          # 解析函数，默认 spider.parse
    method="GET",           # GET/POST/PUT/DELETE...
    headers=None,           # dict
    body=None,              # 请求体（POST 时用）
    cookies=None,           # dict / list[dict] / CookieJar
    meta=None,              # 万能行李舱，传递任意可序列化数据
    encoding="utf-8",       # body/查询字符串的编码
    priority=0,             # 越大越先调度
    dont_filter=False,      # 默认去重；True 强制不过滤
    errback=None,           # 异常回调
    cb_kwargs=None,         # 传给 callback 的具名参数
)
```

### FormRequest 额外参数

```python
scrapy.FormRequest(
    url,
    formdata=None,          # dict 表单字段
    multipart=False,        # True → multipart/form-data；False → urlencoded
    **kwargs,               # 其余同 Request
)
```

### Response 常用属性/方法

| 属性/方法 | 说明 |
| --------- | ---- |
| `response.url` | 最终 URL（已跟随重定向） |
| `response.status` | HTTP 状态码 |
| `response.text` | str，自动解码的网页文本 |
| `response.body` | bytes，原始响应体 |
| `response.headers` | 响应头（大小写不敏感） |
| `response.meta` | 原 request 的 meta 副本 |
| `response.css('选择器')` | 内置 CSS 选择器（`::text` 取文本、`::attr(href)` 取属性） |
| `response.xpath('路径')` | 内置 xpath |
| `response.urljoin('/a.jpg')` | 相对路径拼成绝对 URL |
| `response.json()` | 解析 JSON 响应 |
| `response.follow(url, callback, **kw)` | 返回新 Request，自动 urljoin |
| `response.follow_all(urls, callback, **kw)` | 批量 follow |
| `response.request` | 产生该响应的原始 Request |
| `response.flags` | 调试标记，如 `['redirect']` |
| `response.ip_address` | 远程服务器 IP |
| `response.encoding` | 当前解码编码，可手动修改 |

## 十二、小结

- **开发流程**：`startproject` → `genspider` → 写 `parse`（xpath/css 提取，yield item/request）→ 写 Pipeline（存储）→ 写中间件（UA/代理/加密）→ settings 配置；
- **数据流**：Spider → 调度器 → 下载器（中间件）→ Spider 解析 → Pipeline 存储；
- **提取技巧**：`response.xpath/css` + `get()/getall()`，传参用 `meta`，数据结构用 `Item`，日志用 `spider.logger`；
- **全站爬取**：普通 Spider + LinkExtractor，或 CrawlSpider 的 `rules`；
- **去重**：内置调度器去重、Redis 增量去重、内容指纹去重；
- **分布式**：scrapy-redis 把请求队列和去重集合放进 Redis；
- **反爬**：随机 UA、Cookie 中间件、Referer、代理 IP。
