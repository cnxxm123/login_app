# 1.cookie生成逻辑

服务器生成：
            **<span style="color: #ff0000;">特征(必须记住), 响应头里面通过set-cookie把值带过来. </span>**

浏览器生成:
            <span style="color: #ff0000;">**特征(必须记住), 你在响应头里. 找不到该值. 但是发请求又有这个值...**</span>

# 2.处理逻辑(request处理)

1.直接从浏览器把cookie复制出来.丢到请求头. 直接用即可

```
优点: 简单粗暴
问题: cookie的值是有时效性的. cookie值会过期, 需要重新复制一个
```

2.可以使用resp.cookie, 把响应头中的cookie值拿出来. 传递给下一个请求     

```python
resp = requests.get(url)
resp2 = requests.get(url, cookie=resp.cookie)  # 手工携带cookie
```

3.推荐. python中的requests模块提供了一个叫session的玩意

**注意:如果要给session配置cookie,不要在headers里面配置，请求时传入关键字参数cookies={"cookie":'...'}**

**弊端, 最大的弊端就是: 不能维护js生成的cookie,** 

# 3.验证码逻辑

验证码图片的响应头中会带有cookie。

发送登录请求时要带上验证码图片中的cookie。

# 4.验证码模拟登录

```python
import requests
import ddddocr

session = requests.Session()
#配置session的headers !!!注意:如果要给session配置cookie,不要在headers里面配置，请求时传入关键字参数cookies={"cookie":'...'}
headers = {
    "accept": "image/avif,image/webp,image/apng,image/svg+xml,image/*,*/*;q=0.8",
    "accept-encoding": "gzip, deflate",
    "accept-language": "zh-CN,zh;q=0.9,en;q=0.8,en-GB;q=0.7,en-US;q=0.6",
    "cache-control": "no-cache",
    "connection": "keep-alive",
    "host": "www.woaige.net",
    "pragma": "no-cache",
    "referer": "http://www.woaige.net/login.php?jumpurl=",
    "user-agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) 	Chrome/140.0.0.0 Safari/537.36 Edg/140.0.0.0"
}

session.headers = headers
url_img = "http://www.woaige.net/code.php?0.30224127816537094"  # 验证码图片的url
pre = session.get(url_img)  

with open("woaige.jpg", "wb") as f:  # 保存图片
    f.write(pre.content)
ddd = ddddocr.DdddOcr(show_ad=False)   # 去掉广告
# 读取图片
f = open("woaige.jpg", mode="rb")
# 识别图片
rt = ddd.classification(f.read())   # 字符串
f.close()


url_log  = 'http://www.woaige.net/login.php'
data = {
    "LoginForm[username]": "lzj22",
    "LoginForm[password]": "123456789",
    "LoginForm[captcha]": rt,
    "action": "login",
    "submit": "登  录",
}
log_pre = session.post(url_log,data = data)  # 登录
book = session.post('http://www.woaige.net/bookcase.php',)  # 访问书架页面
print(book.text)
```
