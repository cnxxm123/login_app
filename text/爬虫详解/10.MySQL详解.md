# MySQL 详解

## 一、MySQL 是什么？

MySQL 是一种**关系型数据库**（Relational Database Management System），数据以"表"的形式组织。表由**行（记录）**和**列（字段）**构成。

| 概念 | 别名 | 说明 |
| ---- | ---- | ---- |
| 字段 | 列 / column / 属性 | 表的一列，如 sname |
| 记录 | 行 | 表的一行数据 |
| 主键 | primary key | 全表唯一，能唯一定位一条记录（如学号、身份证号） |

---

## 二、表的操作

### 1. 创建表

```sql
create table student (
    sno int(10) primary key auto_increment,   -- 学号：主键 + 自增
    sname varchar(50) not null,               -- 姓名：非空
    sbirthday date not null,                  -- 生日
    saddress varchar(255),                    -- 地址
    sphone varchar(12),                       -- 电话
    class_name varchar(50)                    -- 班级
);
```

### 2. 常用数据类型

| 类型 | 说明 | 举例 |
| ---- | ---- | ---- |
| `int` | 整数 | 18 |
| `double` | 小数 | 99.5 |
| `varchar(n)` | 变长字符串（n 为最大长度） | '周杰伦' |
| `date` | 日期（年月日） | '2020-01-02' |
| `datetime` | 日期时间（年月日时分秒） | '2020-01-02 12:30:00' |
| `text` | 大文本 | 长篇文章 |

### 3. 约束条件

| 约束 | 说明 |
| ---- | ---- |
| `primary key` | 主键，全表唯一，能唯一确定一条数据 |
| `auto_increment` | 主键自增，**必须是整数类型** |
| `not null` | 不允许为空 |
| （默认允许空） | 不加约束即为可空 |
| `default 值` | 设置默认值 |

### 4. 修改表（一般不用，容易出问题）

```sql
-- 添加一列
ALTER TABLE table_name ADD COLUMN column_name datatype;

-- 删除一列
ALTER TABLE table_name DROP COLUMN column_name;

-- 修改一列的数据类型
ALTER TABLE table_name MODIFY COLUMN column_name datatype;

-- 表重命名
ALTER TABLE table_name RENAME TO new_name;
```

### 5. 查看与删除表/数据库

```sql
-- 查看所有数据库
SHOW DATABASES;

-- 切换/使用某个数据库
USE spider_back;

-- 查看当前库的所有表
SHOW TABLES;

-- 查看表结构
DESC student;      -- 或 DESCRIBE student;

-- 查看建表语句
SHOW CREATE TABLE student;

-- 删除表（整个表结构和数据都没了，不可恢复）
DROP TABLE student;

-- 删除数据库
DROP DATABASE spider_back;
```

### 6. TRUNCATE 与 DELETE 的区别（清空表）

| 操作 | 行为 | 自增 id | 可否带 WHERE | 速度 |
| ---- | ---- | ------- | ------------ | ---- |
| `DELETE FROM t` | 逐行删除 | 继续往下数（不复位） | 可以 | 慢 |
| `TRUNCATE TABLE t` | 整表清空 | **重置为初始值** | 不可以 | 快 |

```sql
-- 只清数据，自增 id 从上次的值继续
DELETE FROM student WHERE 1 = 1;

-- 清空整表，自增 id 重新从 1 开始
TRUNCATE TABLE student;

-- 手动重置自增
ALTER TABLE student AUTO_INCREMENT = 1;
```

> 爬虫调试时想"重新跑一遍"，用 `TRUNCATE` 能顺带把自增 id 归零，比 `DELETE` 更干净。但注意 `TRUNCATE` 无法回滚。

## 三、数据操作：增删改查（重点）

### 1. 增（INSERT）

```sql
-- 语法
INSERT INTO table_name (col1, col2, col3...) VALUES (val1, val2, val3);

-- 添加学生信息
INSERT INTO student (sname, sbirthday, saddress, sage, class_name)
VALUES ('周杰伦', '2020-01-02', '北京市昌平区', 18, '二班');
```

**注意**：

- 主键设了自增就不用写，MySQL 自动按自然顺序递增；
- 字符串数据要加**单引号**；数字可加可不加，但**推荐也加**；
- 统一使用单引号（单双引号有差异，统一单引号最稳妥）。

### 2. 删（DELETE）

```sql
-- 语法
DELETE FROM table_name WHERE 条件;

-- 删除学号为 1 的学生
DELETE FROM student WHERE sno = 1;
```

### 3. 改（UPDATE）

```sql
-- 语法
UPDATE table_name SET col1 = val1, col2 = val2... WHERE 条件;

-- 把学号 1 的学生姓名改为王力宏
UPDATE student SET sname = '王力宏' WHERE sno = 1;
```

> ⚠️ **极度重要**：修改和删除数据**必须带 WHERE 条件**，否则会**全表更新/全表删除**！

### 4. 查（SELECT）—— 程序员用得最多

#### 基础查询

```sql
-- 全表查询
SELECT * FROM student;

-- 只查姓名和年龄
SELECT sname, sage FROM student;

-- 按条件查询
SELECT * FROM student WHERE sno = 1;
SELECT * FROM student WHERE sage > 20;

-- 范围查询（两种写法）
SELECT * FROM student WHERE sage >= 20 AND sage <= 40;
SELECT * FROM student WHERE sage BETWEEN 20 AND 40;

-- 模糊查询：姓"张"的学生
--   _ 代表一位字符
--   % 代表多位字符
SELECT * FROM student WHERE sname LIKE '张%';
SELECT * FROM student WHERE sname LIKE '张_';
```

#### 分组查询与聚合函数

需求：查询每个班级学生的平均年龄。

**聚合函数**（SQL 提供 5 种）：

| 函数 | 含义 |
| ---- | ---- |
| `avg(字段)` | 平均值 |
| `sum(字段)` | 求和 |
| `min(字段)` | 最小值 |
| `max(字段)` | 最大值 |
| `count(*)` | 记录数量 |

**配合 GROUP BY 使用**：

```sql
-- 每个班级的平均年龄
SELECT avg(sage), class_name FROM student GROUP BY class_name;

-- 每个班级最小年龄
SELECT min(sage), class_name FROM student GROUP BY class_name;

-- 每个班级最大年龄
SELECT max(sage), class_name FROM student GROUP BY class_name;

-- 每个班级人数
SELECT count(*), class_name FROM student GROUP BY class_name;

-- 每个班级年龄总和
SELECT sum(sage), class_name FROM student GROUP BY class_name;
```

> ⚠️ 分组后，`SELECT` 里**只能放分组字段和聚合函数**，不要放其他普通字段（结果无意义且会报错）。

#### HAVING —— 对聚合结果再筛选

```sql
-- 查询平均年龄在 15 岁以上的班级
SELECT avg(sage), class_name FROM student
GROUP BY class_name
HAVING avg(sage) > 15;
```

**HAVING 与 WHERE 的区别**：

| 关键字 | 作用时机 |
| ------ | -------- |
| `WHERE` | 在**原始数据**上进行筛选（分组之前） |
| `HAVING` | 在**聚合函数计算结果**上筛选（分组之后） |

#### 排序 ORDER BY

```sql
-- 年龄从小到大
SELECT * FROM student ORDER BY sage ASC;

-- 年龄从大到小
SELECT * FROM student ORDER BY sage DESC;
```

#### 分页查询 LIMIT（爬虫入库、数据列表必备）

```sql
-- 每页 10 条，查第 1 页（跳过 0 条）
SELECT * FROM student LIMIT 0, 10;

-- 第 2 页（跳过 10 条）
SELECT * FROM student LIMIT 10, 10;

-- 第 n 页：LIMIT (n-1)*pageSize, pageSize
```

> `LIMIT offset, count`：第一个数表示跳过多少条，第二个数表示取多少条。分页查询是最常用的 SQL 之一。

#### 去重查询 DISTINCT

去掉查询结果中的重复行：

```sql
-- 查询班级列表（每个班级只出现一次）
SELECT DISTINCT class_name FROM student;

-- 去重后再计数
SELECT count(DISTINCT class_name) FROM student;
```

> 爬虫去重：先 `SELECT DISTINCT 字段` 看看库里已有哪些值，避免重复入库。

#### IN / NOT IN 操作

判断字段值是否在某个集合内（比一串 OR 更清晰）：

```sql
-- 查询这两个班级的学生
SELECT * FROM student WHERE class_name IN ('一班', '二班');

-- 等价写法（IN 更直观）
SELECT * FROM student WHERE class_name = '一班' OR class_name = '二班';

-- 排除某几个班级
SELECT * FROM student WHERE class_name NOT IN ('三班');

-- 配合子查询（见下方多表章节）
SELECT * FROM stu WHERE sid IN (SELECT s_id FROM sc WHERE score > 90);
```

#### 合并查询 UNION / UNION ALL

把多个 SELECT 的结果**纵向拼接**成一张结果集：

```sql
-- UNION：去重合并
SELECT sname FROM stu_2020
UNION
SELECT sname FROM stu_2021;

-- UNION ALL：不去重合并（更快，重复也保留）
SELECT sname FROM stu_2020
UNION ALL
SELECT sname FROM stu_2021;
```

| 关键字 | 是否去重 | 速度 |
| ------ | -------- | ---- |
| `UNION` | 去重 | 较慢（要排序去重） |
| `UNION ALL` | 不去重 | 快 |

> 使用条件：各 SELECT 的**列数量必须一致**，数据类型尽量一致。爬虫合并多张同结构表的数据时常用。

#### 用 EXPLAIN 分析查询（性能调优）

`EXPLAIN` 可以查看 MySQL 如何执行一条查询，是排查慢 SQL 的关键工具：

```sql
EXPLAIN SELECT * FROM student WHERE sname = '周杰伦';
```

重点看这几个字段：

| 字段 | 含义 | 好坏判断 |
| ---- | ---- | -------- |
| `type` | 访问类型 | `const/eq_ref` 最好；`ref` 好；`range` 一般；`ALL`（全表扫）**最差** |
| `rows` | 预估扫描行数 | 越小越好 |
| `key` | 实际使用的索引 | 为 `NULL` 说明没走索引 |
| `Extra` | 额外信息 | 出现 `Using filesort` / `Using temporary` 说明有优化空间；`Using index` 是最优（覆盖索引） |

```sql
-- 对比：建索引前后 type 的变化（ALL → ref）
CREATE INDEX idx_sname ON student(sname);
EXPLAIN SELECT * FROM student WHERE sname = '周杰伦';   -- type 变为 ref
```

> 爬虫批量入库后查询变慢，先用 `EXPLAIN` 看是不是全表扫描（type=ALL），再决定是否建索引。

## 三·五、索引与事务（了解）

### 1. 索引（Index）

索引相当于书的**目录**，能让查询大幅提速，但会占用额外空间、拖慢写入。

```sql
-- 给字段创建普通索引
CREATE INDEX idx_sname ON student(sname);

-- 创建唯一索引（字段值不重复时用）
CREATE UNIQUE INDEX idx_sno ON student(sno);

-- 查看索引
SHOW INDEX FROM student;

-- 删除索引
DROP INDEX idx_sname ON student;
```

> 爬虫中如果经常按某个字段（如 URL、标题）查询，建议给它建索引；但**不要盲目给所有字段加索引**。

### 2. 事务（Transaction）

事务保证"要么全部成功，要么全部失败"。经典场景：转账。

```sql
-- 开启事务
START TRANSACTION;

UPDATE account SET money = money - 100 WHERE name = '张三';
UPDATE account SET money = money + 100 WHERE name = '李四';

-- 全部成功才提交，任何一步失败则回滚
COMMIT;      -- 或 ROLLBACK;
```

> 事务的四大特性 ACID：原子性（Atomicity）、一致性（Consistency）、隔离性（Isolation）、持久性（Durability）。爬虫批量入库时常用事务一次提交多条，提高效率。

### 3. 防重复入库：INSERT ... ON DUPLICATE KEY UPDATE（爬虫必备）

爬虫重复抓取很常见，与其"先查再插"，不如让数据库"遇到主键/唯一键重复就更新"：

```sql
-- 表结构（url 是唯一键）
CREATE TABLE news (
    id int PRIMARY KEY AUTO_INCREMENT,
    url varchar(255) UNIQUE,        -- 唯一键
    title varchar(255),
    views int default 0
);

-- 重复（url 已存在）时：不报错，而是更新 views
INSERT INTO news(url, title, views) VALUES ('http://a.com', '标题', 10)
ON DUPLICATE KEY UPDATE views = views + 1;
```

- 原理：当插入遇到主键/唯一键冲突时，自动执行 `UPDATE` 子句；
- 与"先查后插"相比：省一次查询、逻辑更简单、性能更好；
- 注意：必须有**主键或唯一键**才能触发该机制。

### 4. REPLACE INTO（覆盖式插入）

`REPLACE INTO` 遇到唯一键冲突时会**先删除旧记录再插入新记录**（会改变自增 id）：

```sql
-- 存在则删除重建，不存在则直接插入
REPLACE INTO news(url, title) VALUES ('http://a.com', '新标题');
```

| 写法 | 冲突时行为 | 影响 id |
| ---- | ---------- | ------- |
| `INSERT ... ON DUPLICATE KEY UPDATE` | 更新原记录 | 不变 |
| `REPLACE INTO` | 删旧插新 | 会变 |
| 普通 `INSERT` | 报错 | - |

> 需要保留自增 id 连续性/关联外键时用 `ON DUPLICATE KEY UPDATE`，否则可用 `REPLACE`。

### 5. 常用 SQL 函数补充

| 函数 | 作用 | 示例 |
| ---- | ---- | ---- |
| `NOW()` | 当前时间 | `INSERT ... VALUES(..., NOW())` |
| `DATEDIFF(a, b)` | 两个日期相差天数 | `SELECT DATEDIFF(NOW(), '2020-01-01')` |
| `CONCAT(a, b)` | 字符串拼接 | `SELECT CONCAT(sname, '同学') FROM student` |
| `IFNULL(x, 默认值)` | x 为空时返回默认值 | `SELECT IFNULL(saddress, '未知') FROM student` |
| `DATE_FORMAT(d, 格式)` | 格式化日期 | `SELECT DATE_FORMAT(NOW(), '%Y-%m-%d %H:%i')` |
| `GROUP_CONCAT(x)` | 分组内拼接（常配合 GROUP BY） | `SELECT class_name, GROUP_CONCAT(sname) FROM student GROUP BY class_name` |

## 四、多表联合查询

实际业务中一张表不够用，例如学生选课系统可设计为三张表：

1. **学生表**：学号、姓名、性别、住址
2. **课程表**：课程编号、课程名称、授课教师
3. **成绩表**：成绩表编号、学号、课程编号、成绩

> 这样的设计：表结构清晰、无冗余（符合第三范式）。成绩表通过主外键把学生表和课程表关联起来——**把 A 表的主键放到 B 表作为普通字段，且数据必须来自 A 表**，就是主外键关系。

### 建表语句

```sql
-- 学生表
CREATE TABLE stu (
    sid int PRIMARY KEY AUTO_INCREMENT,
    sname varchar(50) NOT NULL,
    gender int(1),
    address varchar(255)
);

-- 课程表
CREATE TABLE course (
    cid int PRIMARY KEY AUTO_INCREMENT,
    cname varchar(50) NOT NULL,
    teacher varchar(50)
);

-- 成绩表（含外键）
CREATE TABLE sc (
    sc_id int PRIMARY KEY AUTO_INCREMENT,
    s_id int,                     -- 学号（外键）
    c_id int,                     -- 课程编号（外键）
    score int,                    -- 成绩
    CONSTRAINT fk_sc_stu_s_id FOREIGN KEY (s_id) REFERENCES stu(sid),
    CONSTRAINT fk_sc_course_c_id FOREIGN KEY (c_id) REFERENCES course(cid)
);
```

### 1. 子查询

把一个查询的结果作为另一个查询的条件：

```sql
-- 查询选择了"编程"这门课的学生
SELECT * FROM stu WHERE sid IN (
    SELECT s_id FROM sc WHERE c_id IN (
        SELECT cid FROM course WHERE cname = '编程'
    )
);

-- 查询课程名称为"编程"、且分数低于 60 的学生姓名和分数
SELECT stu.sname, sc.score
FROM stu, sc
WHERE stu.sid = sc.s_id
  AND sc.score < 60
  AND sc.c_id IN (SELECT cid FROM course WHERE cname = '编程');
```

### 2. 关联查询（JOIN）

把多张表通过 `JOIN ... ON 关联条件` 合并后检索。通常 `ON` 后面的就是主外键关系。

```
SELECT * FROM A xxx JOIN B ON A.字段1 = B.字段2;
```

#### INNER JOIN（内连接：只保留两表都匹配的记录）

```sql
-- 查询每门课程被选修的学生数
SELECT c.cid, c.cname, count(*)
FROM sc
INNER JOIN course c ON sc.c_id = c.cid
GROUP BY c.cid, c.cname;
```

#### LEFT JOIN（左连接：保留左表全部记录，右表无匹配则为 NULL）

```sql
-- 查询所有学生的选课情况（即使某学生没选课也会显示）
SELECT s.sname, c.cname
FROM stu s
LEFT JOIN sc ON s.sid = sc.s_id
LEFT JOIN course c ON sc.c_id = c.cid;

-- 查询任何一门课程成绩在 70 分以上的姓名、课程名称和分数
SELECT s.sname, c.cname, sc.score
FROM stu s
INNER JOIN sc ON s.sid = sc.s_id
INNER JOIN course c ON sc.c_id = c.cid
WHERE sc.score > 70;
```

#### RIGHT JOIN（右连接：保留右表全部记录，左表无匹配则为 NULL）

与 `LEFT JOIN` 方向相反，右表全部保留。LEFT 用得比 RIGHT 多，会写 LEFT 即可，RIGHT 见得到认识：

```sql
-- 保留课程表全部记录，没有学生选修的课程也显示（课程名在右表 course）
SELECT s.sname, c.cname
FROM stu s
RIGHT JOIN sc ON s.sid = sc.s_id
RIGHT JOIN course c ON sc.c_id = c.cid;
```

#### 四种 JOIN 小结

| JOIN 类型 | 结果 |
| --------- | ---- |
| `INNER JOIN` | 两表**都匹配**的记录（交集） |
| `LEFT JOIN` | **左表全部** + 右表匹配，无匹配补 NULL |
| `RIGHT JOIN` | **右表全部** + 左表匹配，无匹配补 NULL |
| `CROSS JOIN`（笛卡尔积） | 两表所有行两两组合（很少用） |

```sql
-- CROSS JOIN：A 表 3 行 × B 表 4 行 = 12 行
SELECT * FROM stu CROSS JOIN course;
```

## 五、Python 连接 MySQL（pymysql）

### 安装

```bash
pip install pymysql
```

### 连接数据库

```python
import pymysql

conn = pymysql.connect(
    host="localhost",      # 地址
    port=3306,             # 端口
    user="root",           # 用户名
    password="test123456", # 密码
    database="spider_back" # 数据库名
)

# 创建游标（操作数据库的"手"）
cursor = conn.cursor()

# ... 各种增删改查操作 ...

cursor.close()   # 关闭游标
conn.close()     # 关闭连接
```

### 5.1 增删改（需要 commit 提交）

```python
# 添加数据
try:
    cursor = conn.cursor()
    result = cursor.execute(
        "insert into stu(sname, address, gender) values ('李嘉诚', '八宝山', 1)"
    )
    print(cursor.lastrowid)   # 获取自增的 ID 值
    print(result)             # 受影响的行数
    conn.commit()             # 提交事务（必须！）
except:
    conn.rollback()           # 失败回滚

cursor.close()
conn.close()
```

```python
# 修改数据
try:
    cursor = conn.cursor()
    result = cursor.execute("update stu set gender = 2 where sid = 12")
    print(result)
    conn.commit()
except:
    conn.rollback()

cursor.close()
conn.close()
```

```python
# 删除数据
try:
    cursor = conn.cursor()
    result = cursor.execute("delete from stu where sid = 12")
    print(result)
    conn.commit()
except:
    conn.rollback()

cursor.close()
conn.close()
```

> **要点**：增删改必须 `conn.commit()` 提交事务，否则不生效；出错用 `conn.rollback()` 回滚。

### 5.2 查询操作

```python
from pymysql.cursors import DictCursor

# 默认游标：返回元组
# cursor = conn.cursor()
# 字典游标：返回字典，字段名即 key（推荐）
cursor = conn.cursor(DictCursor)

sql = "select * from stu"
ret_num = cursor.execute(sql)   # 返回结果条数

# result = cursor.fetchall()    # 获取全部结果
# result = cursor.fetchmany(5)  # 获取部分结果
result = cursor.fetchone()      # 获取单个结果，可连续获取
print(result)
result = cursor.fetchone()
print(result)

cursor.close()
conn.close()
```

> **注意**：一个游标被取空后，就不能再获取内容了。

### 5.3 参数化查询（防 SQL 注入，推荐）

```python
cursor = conn.cursor()
sql = "insert into stu(sname, address, gender) values (%s, %s, %s)"
cursor.execute(sql, ("王力宏", "北京市", 1))
conn.commit()
```

> 永远不要用字符串拼接 SQL，要用 `%s` 占位符 + 参数元组，防止 SQL 注入。

### 5.4 远程连接配置

MySQL 默认只允许本机连接。要远程连接，需在 MySQL 命令行执行：

```sql
GRANT ALL PRIVILEGES ON *.* TO 'root'@'%' WITH GRANT OPTION;
FLUSH PRIVILEGES;
```

> 生产中请使用专用账号并限制权限，不要用 root 开放所有来源。

### 5.5 executemany 批量插入（爬虫入库提速神器）

爬虫攒了一大批数据，逐条 `execute` 太慢，用 `executemany` 一次批量插入：

```python
cursor = conn.cursor()

# 参数是一个"列表，每个元素是一条记录的参数元组"
data = [
    ("周杰伦", "北京", 1),
    ("王力宏", "上海", 1),
    ("蔡依林", "广州", 0),
]

sql = "insert into stu(sname, address, gender) values (%s, %s, %s)"
cursor.executemany(sql, data)
conn.commit()
print("受影响行数:", cursor.rowcount)
```

> 性能对比：10 万条数据用 `executemany` 可能几秒，逐条 `execute` 可能要几分钟——因为减少了大量网络往返和日志写入。

### 5.6 用 with 语句管理连接与游标

`pymysql` 的连接和游标都支持上下文管理，自动提交/回滚、自动关闭，代码更整洁：

```python
import pymysql

# with conn：正常结束自动 commit，出异常自动 rollback
with pymysql.connect(
    host="localhost", port=3306,
    user="root", password="123456", database="spider"
) as conn:
    # with cursor：用完自动关闭游标
    with conn.cursor() as cursor:
        cursor.execute(
            "insert into stu(sname, address, gender) values (%s, %s, %s)",
            ("周杰伦", "北京", 1),
        )
# 退出 with 后连接自动关闭
```

> 注意：`with conn` 只对"执行了写操作"的情况自动提交；只查询时它也会正常关闭连接，是推荐的规范写法。

### 5.7 连接池（高并发时避免频繁建连）

爬虫多线程并发入库时，每次都新建连接开销大。用 `DBUtils` 连接池复用连接：

```bash
pip install DBUtils
```

```python
from dbutils.pooled_db import PooledDB
import pymysql

pool = PooledDB(
    creator=pymysql,
    host="localhost", port=3306,
    user="root", password="123456", database="spider",
    maxconnections=10,      # 连接池最大连接数
)

conn = pool.connection()    # 从池中取连接（用完归还）
cursor = conn.cursor()
cursor.execute("select * from stu limit 3")
print(cursor.fetchall())
cursor.close()
conn.close()                # 归还到连接池，而非真正关闭
```

> 连接池适合"多线程 + 频繁入库"的爬虫；单线程小规模数据用普通的 `connect` 即可，不必过度设计。

### 5.8 字符集与中文乱码（utf8mb4）

插入中文报 `Incorrect string value` 或读出乱码，99% 是字符集问题。**务必统一使用 `utf8mb4`**（MySQL 8 默认）：

```python
import pymysql

conn = pymysql.connect(
    host="localhost", port=3306,
    user="root", password="123456",
    database="spider",
    charset="utf8mb4",          # 关键：让连接层也用 utf8mb4
    cursorclass=pymysql.cursors.DictCursor,   # 直接指定字典游标
)
```

```sql
-- 建库/建表也统一 utf8mb4
CREATE DATABASE spider DEFAULT CHARACTER SET utf8mb4;
CREATE TABLE stu (
    id int primary key auto_increment,
    sname varchar(50)
) DEFAULT CHARSET=utf8mb4;
```

> 排查顺序：① 连接加 `charset="utf8mb4"`；② 库/表字符集改为 `utf8mb4`；③ 数据本身不是乱码（页面先 `resp.encoding` 处理好）。三者都对了，中文一定正常。

### 5.9 自动提交 autocommit 与多行 INSERT

嫌每次都要 `commit()` 麻烦？可开启自动提交（`autocommit=True`），但注意**失去回滚保护**：

```python
import pymysql

# 开启自动提交：每次 execute 写操作立即生效，无需手动 commit
conn = pymysql.connect(
    host="localhost", port=3306,
    user="root", password="123456",
    database="spider",
    autocommit=True,
)
cursor = conn.cursor()
cursor.execute("insert into stu(sname) values ('周杰伦')")   # 立即生效
```

不想开自动提交，又想一次插多行，SQL 本身支持**多值插入**：

```python
# 一条 SQL 插多条（比 executemany 更省一次往返，也常用）
sql = "insert into stu(sname, address) values (%s, %s), (%s, %s), (%s, %s)"
cursor.execute(sql, ("周杰伦", "北京", "王力宏", "上海", "蔡依林", "广州"))
conn.commit()
```

> 建议：需要"出错可回滚"的批量入库用 `autocommit=False + commit/rollback`；数据无所谓、追求简单的场景可以开 `autocommit=True`。

## 六、爬虫存储数据到 MySQL 的完整示例

```python
import pymysql

class MoviePipeline:
    def __init__(self):
        self.conn = pymysql.connect(
            host="localhost", port=3306,
            user="root", password="123456",
            database="spider"
        )

    def save(self, title, score):
        cursor = self.conn.cursor()
        sql = "insert into movie(title, score) values (%s, %s)"
        try:
            cursor.execute(sql, (title, score))
            self.conn.commit()
        except Exception as e:
            self.conn.rollback()
            print("保存失败:", e)
        finally:
            cursor.close()

    def close(self):
        self.conn.close()

# 使用
pipeline = MoviePipeline()
pipeline.save("流浪地球", 9.5)
pipeline.close()
```

## 七、小结

- 建表：`CREATE TABLE` + 数据类型 + 约束（主键、自增、非空）；
- 增删改查：`INSERT / DELETE / UPDATE / SELECT`，**改删务必带 WHERE**；
- 聚合：`avg/sum/min/max/count + GROUP BY`，聚合后再筛选用 `HAVING`；
- 高级查询：`DISTINCT` 去重、`IN` 集合判断、`UNION/UNION ALL` 合并结果、`EXPLAIN` 分析慢 SQL；
- 分页：`LIMIT offset, count`；提速：适当建索引；批量：用事务 commit/rollback；
- 防重复入库：`INSERT ... ON DUPLICATE KEY UPDATE`（保留 id）或 `REPLACE INTO`（删旧插新）；
- 多表：子查询（嵌套 WHERE）、`INNER JOIN`（都匹配）、`LEFT JOIN`（保左表）；
- Python：`pymysql` 连接 → 游标执行 → 增删改要 `commit`，查询用 `fetchone/fetchall`，参数用 `%s` 占位防注入；
- 性能优化：`executemany` 批量插入、`with` 管理连接/游标、`DBUtils` 连接池应对高并发。
