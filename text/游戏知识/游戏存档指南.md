# 游戏存档完全指南

> 一句话：**存档 = 游戏的"进度"**，配置是"设置"（见《游戏配置指南》）。

---

## 一、怎么找存档（不用判断引擎）

### 方法 1：撒网搜索（最通用）

90% 的存档就藏在这几个地方，挨个搜：

```
C:\Users\你的用户名\
├── AppData\Roaming\游戏名\
├── AppData\Local\游戏名\
├── AppData\LocalLow\游戏名\
└── Documents\My Games\游戏名\
```

**实操**：`Win+E` 打开文件资源管理器 → 搜索框输入游戏英文名（`*游戏名*`）→ 范围选"此电脑"。

### 方法 2：让游戏自己暴露位置（最准）

- **Steam**：库里右键游戏 → 管理 → 浏览本地文件，进游戏目录找 `save` / `config` 文件夹
- **游戏内设置页**：有的游戏有"打开存档文件夹"按钮
- **任务管理器**：游戏运行时右键进程 → "打开文件所在的位置"

### 方法 3：看安装目录判断

打开安装目录，有没有 `config.ini` / `settings` / `save` / `Saves`？

- 有 → **根目录型**，存档就在游戏目录里
- 没有 → **现代游戏**，去上面的用户目录搜

## 二、存档位置速查表

| 场景 | 位置 |
|------|------|
| **老式单机 / 绿色版** | 游戏根目录 `save\`（如 RE4 的 `win64_save\`） |
| **现代游戏** | `%appdata%` 系列 + `Documents\My Games\游戏名\` |
| **Unity** | `AppData\LocalLow\公司名\游戏名\`（默认；开发者可改，找不到就撒网搜） |
| **Unreal** | `AppData\Local\游戏名\Saved\SaveGames\` |
| **Godot** | `AppData\Roaming\Godot\app_userdata\项目名\` |
| **Steam 云镜像** | `Steam\userdata\<你的ID>\<AppID>\remote\` |
| **主机**（PS/Switch/Xbox） | 主机内建存储，PC 拿不到 |

---

## 三、Steam 云存档 = 一份存档 + 云端同步

**不是两份进度**！只是同一份进度的"本地 + 云端镜像"：

```
游戏写入 → 本地存档（真实进度）
              ↓ Steam 客户端上传
         → Steam 云服务器（备份/镜像）
              ↓ 换设备/重装
         → 下载回本地
```

**两个文件别搞混：**

| 文件 | 位置 | 作用 |
|------|------|------|
| `remotecache.vdf` | 每个游戏 `userdata\<ID>\<AppID>\` 内 | 云同步"账本"（记录有哪些存档、状态），不是存档本体 |
| `steam_autocloud.vdf` | Steam 安装目录 `config\`（全局） | 云"身份证"（绑定账户云 ID） |

**要点：**
- 云存档 = 备份/镜像，**不是另一份进度**；改了本地云跟着同步
- 云是同步**不是永久保险**，服务器端也可能丢/冲突
- 关云/没开云 → 只有本地一份，删了真没了
- ⚠️ **别复制别人的 `steam_autocloud.vdf`**（云身份证借给别人 = 云存档认错主、错乱）
- 备份时只需拷 `remote\` 里的存档文件，不用管 vdf

## 四、存档的后缀与命名

**后缀：**

```
.sav   .save   .dat   .bin   .slot   .profile
```

多为二进制或引擎专属格式，一般不能直接改。

**命名：**

```
save.dat        savegame.sav    slot1.sav
profile.dat     autosave.sav    quick.sav
```

**规律：** 名字常带 `save` / `saved` / `slot` / `profile` / `autosave`，一眼可辨。

**RE4 重制版实例（根目录型/绿色版）：** 配置文件 `local_config.ini`，存档在游戏根目录 `win64_save\` 或 `save\`。

---

## 核心总结（4 条）

1. **不用判断引擎也能找**：用户目录搜游戏英文名 + 看安装目录有没有 `save` / `config`，两招覆盖 90%。
2. **存档别放安装目录**，统一在用户目录（`%appdata%` 系列 + `Documents`）。
3. **默认位置速记**：Unity → LocalLow、Unreal → Saved\SaveGames、Godot → app_userdata（都是"默认"，找不到就撒网搜）。
4. **Steam 云 = 一份本地存档 + 云端镜像**，镜像在 `userdata\<ID>\<AppID>\remote\`；别复制别人的 `steam_autocloud.vdf`。
