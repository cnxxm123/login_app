# CSS 层叠样式表 详解

## 一、CSS 是什么？

CSS 全称 **Cascading Style Sheets（层叠样式表）**，负责网页的"外观美化"。

| 角色 | 类比 |
| ---- | ---- |
| HTML | 页面骨架（素颜） |
| CSS | 页面美化（美妆 + 滤镜） |

CSS 的核心思想：**用"选择器"选中页面上的元素，再对选中的元素设置样式**。

### 1. 基本语法

```css
选择器 {
    属性: 值;
    属性: 值;
    ...
}
```

示例：

```css
p {
    color: red;         /* 文字颜色 */
    font-size: 20px;    /* 字体大小 */
    background: #eee;   /* 背景色 */
}
```

### 2. 命名规则

- 由字母、数字、下划线 `_`、减号 `-` 组成；
- **不能以数字开头**。

### 3. 注释

```css
/* 这是 CSS 注释 */
```

---

## 二、在 HTML 中使用 CSS 的三种方式

### 1. 内联样式（行内样式）

直接写在标签的 `style` 属性中：

```html
<p style="color: blue; font-family: 隶书">我是内联样式</p>
```

- 特点：**只作用于当前这一个标签**；
- 缺点：无法复用，代码冗余，不推荐批量使用。

### 2. 内部样式（内嵌样式）

写在 `<head>` 里的 `<style>` 标签中：

```html
<head>
    <style type="text/css">
        p {
            color: blue;
        }
    </style>
</head>
```

- 特点：**作用于当前整个页面**。

### 3. 外部样式（外部链入）⭐推荐

单独编写 `.css` 文件，用 `<link>` 引入：

```html
<head>
    <link rel="stylesheet" type="text/css" href="style.css" />
</head>
```

- 特点：**作用于整个网站**，样式可以多处复用，便于维护。

#### 补充：`@import` 引入（了解）

除了 `<link>`，CSS 文件内部还可以用 `@import` 再引入别的 CSS：

```css
/* style.css 顶部 */
@import url("reset.css");
@import "theme.css";
```

| 方式 | 写在 | 加载时机 | 推荐度 |
| ---- | ---- | -------- | ------ |
| `<link>` | HTML 的 head | 与 HTML 并行加载 | ⭐推荐 |
| `@import` | CSS 文件内部 | 需等所在 CSS 先加载 | 少用 |

> **爬虫视角**：要还原页面样式时，先看 `<link>` 引了哪些 css，再看 css 里有没有 `@import`；字体加密等反爬资源可能藏在被引入的 css 里。

> **爬虫视角**：我们通常**不关心**页面长什么样，但 CSS 的**选择器语法**必须掌握，因为解析库（bs4 的 `select()`、scrapy 的 `response.css()`）都直接使用 CSS 选择器来定位数据。

## 三、CSS2 的基础选择器

### 1. 标签选择器（元素选择器）

直接用 HTML 标签名作为选择器，选中页面中**所有**该标签：

```css
p { color: blue; }    /* 所有 p 标签 */
h2 { font-size: 30px; }  /* 所有 h2 标签 */
```

### 2. class 类选择器

用 `.类名` 定义，选中所有 `class` 属性值为该类名的元素：

```css
.mc { color: blue; }          /* class="mc" 的所有元素 */
p.mc { color: green; }        /* 是 p 且 class="mc" 的元素 */
```

HTML 中引用：

```html
<p class="mc">这段文字是蓝色</p>
```

- **特点**：类选择器可以**在网页中重复使用**（同一个 class 可以用于多个元素）。

### 3. ID 选择器

用 `#id名` 定义，选中 `id` 属性为该值的**唯一**元素：

```css
#jay { color: green; }
```

HTML 中引用：

```html
<span id="jay">我只有一个</span>
```

- **特点**：`id` 在页面中**只能出现一次**（唯一标识）。

### 4. 关联选择器（后代选择器）

用**空格**连接，表示"某个选择器内部的元素"：

```css
table a { color: red; }     /* table 标签内部的所有 a 标签 */
h1 p { color: red; }        /* h1 内部的 p 标签 */
```

### 5. 组合选择器（选择器分组）

用**逗号**连接多个选择器，让它们共用同一套样式：

```css
h3, h4, h5 { color: green; }   /* h3、h4、h5 都生效 */
```

## 四、CSS3 的进阶选择器

### 1. 关系选择器

```css
div > p { ... }    /* 选择 div 的直接子元素 p（仅限一层父子关系） */
div + p { ... }    /* 选择紧跟在 div 后面的第一个兄弟 p */
div ~ p { ... }    /* 选择 div 后面的所有兄弟 p */
```

**后代选择器 vs 子选择器的区别**：

```css
/* 后代选择器：所有层级中的 p 都命中 */
div p { color: red; }

/* 子选择器：只有 div 的直接子级 p 命中 */
div > p { color: red; }
```

### 2. 属性选择器

```css
[attribute] { ... }            /* 具有该属性的元素 */
[attribute="value"] { ... }    /* 属性值等于 value 的元素 */
[attribute^="abc"] { ... }     /* 属性值以 abc 开头 */
[attribute$="abc"] { ... }     /* 属性值以 abc 结尾 */
[attribute*="abc"] { ... }     /* 属性值包含 abc */
```

```css
code[abc="haha"] { color: green; }
```

#### 2.1 通配符与高级伪类（:is / :where / :has）

```css
/* 通配符：选中所有元素 */
* { margin: 0; padding: 0; }

/* :is()：多个选择器取"并集"，写得更短（可传复杂选择器） */
:is(h1, h2, h3) { color: red; }              /* 等价于 h1,h2,h3 */
div :is(.a, .b) { color: blue; }             /* div 内 .a 或 .b */

/* :where()：同 :is()，但优先级始终为 0（方便被覆盖） */
:where(.box, .card) { color: gray; }

/* :has()：包含某元素的父元素（"父级选择器"，很实用） */
div:has(> a) { background: #eee; }           /* 内部有直接子 a 的 div */
li:has(.price) { border: 1px solid red; }    /* 含 .price 的 li */
```

| 选择器 | 含义 | 爬虫用途 |
| ------ | ---- | -------- |
| `*` | 所有元素 | 配合后代/子级写通用规则 |
| `:is(a,b)` | 多个选择器并集 | 缩短选择器写法 |
| `:where(a,b)` | 同 `:is` 但权重为 0 | 很少用 |
| `:has(子选择器)` | **包含**某子元素的父元素 | 定位"含价格/含链接"的父容器，比一层层往上找方便 |

```python
# bs4 中用 :has 定位"含 .price 的商品条目"
from bs4 import BeautifulSoup
html = '<li><span class="name">手机</span><span class="price">99</span></li><li><span>无价格</span></li>'
soup = BeautifulSoup(html, "html.parser")
print([li.text for li in soup.select("li:has(.price)")])   # ['手机99']
```

> `:has()` 需要较新浏览器/解析库支持（bs4 的 css select 用 soupsieve 支持），老环境里可用 xpath `//li[.//*[@class='price']]` 等价替代。

### 3. 伪类选择器（常用）

```css
a:hover { color: red; }        /* 鼠标悬停时 */
li:first-child { ... }         /* 第一个子元素 */
li:nth-child(2) { ... }        /* 第 2 个子元素 */
li:last-child { ... }          /* 最后一个子元素 */
```

**更多实用伪类（爬虫定位常用）**：

```css
li:not(.active) { ... }        /* 排除某个 class 的元素（:not 取反） */
li:nth-child(odd) { ... }      /* 奇数位子元素（隔行变色常用） */
li:nth-child(even) { ... }     /* 偶数位子元素 */
li:nth-child(3n+1) { ... }     /* 每 3 个取第 1 个（n 从 0 开始） */
p:first-of-type { ... }        /* 同类型元素中第一个 */
p:last-of-type { ... }         /* 同类型元素中最后一个 */
p:empty { ... }                /* 没有任何子元素/文本的空标签 */
li:only-child { ... }          /* 唯一的子元素 */
:root { ... }                  /* 根元素（即 html），常用于定义 CSS 变量 */
```

```css
/* 实际应用：排除导航栏，只取内容区 */
div.content p:not(.no) { color: #333; }
```

> **爬虫视角**：抓"分页/列表"时常用 `nth-child(3n+1)` 等规律选择器批量跳过分隔符/广告位；`:not()` 用来排除干扰项（如"置顶"、"广告"）。注意 `:not` 括号里在 CSS3 只支持简单选择器（标签/类/id/属性），CSS4 才支持复杂选择器。

**`nth-child` 与 `nth-of-type` 的区别（高频考点）**：

- `:nth-child(n)`：按**所有子元素**的先后顺序数，不管类型；
- `:nth-of-type(n)`：只按**同类型元素**的先后顺序数。

```html
<ul>
    <span>我是 span</span>
    <li>第 1 个 li</li>
    <li>第 2 个 li</li>
    <li>第 3 个 li</li>
</ul>
```

```css
ul li:nth-child(2) { color: red; }    /* 命中的是"第 1 个 li"（因为 span 占了第 1 位） */
ul li:nth-of-type(2) { color: red; }  /* 命中的是"第 2 个 li"（只数 li） */
```

> 爬虫提取表格/列表时常用 `:nth-child` 定位"第几列/第几行"，遇到标签混排的情况请改用 `:nth-of-type`。

### 4. 常用伪元素

```css
/* 在元素内容前/后插入内容（常用于图标、引号） */
p::before { content: "▶ "; }
p::after  { content: " ◀"; }
```

> 如果发现用 xpath/bs4 取文本时**前后多了字符**，往往是伪元素造成的，需要清洗。

### 5. 常用状态伪类

```css
a:link    { color: blue; }    /* 未访问的链接 */
a:visited { color: gray; }    /* 已访问的链接 */
a:hover   { color: red; }     /* 鼠标悬停 */
a:active  { color: green; }   /* 鼠标按下 */
input:focus { border-color: blue; }   /* 输入框获得焦点 */
input:checked { outline: 1px solid red; }  /* 被选中的单选框/复选框 */
```

## 五、CSS 在爬虫解析中的实战用法

### 1. 在 BeautifulSoup 中使用 CSS 选择器

```python
from bs4 import BeautifulSoup

html = """
<html>
<body>
    <div class="goods-list">
        <div class="goods-item">
            <a href="/1.html" class="name">苹果手机</a>
            <span class="price">5999</span>
        </div>
        <div class="goods-item">
            <a href="/2.html" class="name">华为平板</a>
            <span class="price">2999</span>
        </div>
    </div>
</body>
</html>
"""

soup = BeautifulSoup(html, "html.parser")

# 用 CSS 选择器提取所有商品条目
items = soup.select("div.goods-item")

for item in items:
    # 后代选择器：item 内的 .name 链接
    name = item.select_one("a.name").text
    # 类选择器 .price
    price = item.select_one("span.price").text
    # 属性选择器取 href
    href = item.select_one("a.name").get("href")
    print(name, price, href)
```

### 2. 在 scrapy 中使用 CSS 选择器

```python
import scrapy

class DemoSpider(scrapy.Spider):
    name = "demo"

    def parse(self, response):
        # response.css() 返回选择器列表
        for item in response.css("div.goods-item"):
            name = item.css("a.name::text").get()
            price = item.css("span.price::text").get()
            yield {"name": name, "price": price}
```

> 注意 scrapy 中取文本用 `::text`，取属性用 `::attr(属性名)`，这是与普通 CSS 略有差异的地方。

## 六、层叠与优先级（理解"层叠"的含义）

CSS 取名"Cascading（层叠）"，是因为**当多个规则同时命中一个元素时，按优先级决定谁生效**。

### 1. 优先级权重（重点）

| 选择器类型 | 权重示例 | 权重值 |
| ---------- | -------- | ------ |
| 内联样式 | `style="..."` | 1000 |
| ID 选择器 | `#jay` | 100 |
| 类 / 属性 / 伪类 | `.mc` `[href]` `:hover` | 10 |
| 标签 / 伪元素 | `p` `::before` | 1 |
| 通配符 | `*` | 0 |

**计算规则**：把所有选择器的权重**相加**，大的生效；相同则**后写的生效**。

```css
/* 权重 1+10+100 = 111 */
div .price #buy { color: red; }

/* 权重 1+10+10 = 21，小于上面的 111 */
div span b { color: blue; }

/* 权重 10+10+1 = 21，且写在后 -> 与上面同权时生效 */
.pic-list b { color: green; }
```

### 2. `!important` 最高优先级

```css
p { color: red !important; }   /* 无视其他所有规则 */
```

> 爬虫一般不需要计算优先级，但**了解"哪个样式会生效"有助于判断元素是否被隐藏/偏移**（比如某些网站把真实文字用 CSS 隐藏、用图片/字体偏移来反爬）。

### 3. 反爬应用：CSS 隐藏

```css
/* 方法一：隐藏（元素不可见） */
.secret { display: none; }

/* 方法二：缩进移出屏幕（元素还在文档流中） */
.secret { text-indent: -9999px; }
```

> 如果页面上的文字在 `resp.text` 里**找不到**，检查它是不是被 `display:none` 或偏移隐藏了——这时数据可能藏在 CSS 引用的字体/背景图里。

### 4. 反爬应用：字体加密（@font-face，重点）

这是国内网站（如豆瓣、猫眼、汽车之家）常用的**反爬手段**：页面文字表面正常，但**实际用的是一套自定义字体**，把常见字符（数字/汉字）映射到"乱码字形"上。浏览器能正常显示，爬虫抓到的却是乱码。

```css
/* 网站 CSS 里通常这样引入加密字体 */
@font-face {
    font-family: "myFont";
    src: url("//xxx.com/font/abc123.woff") format("woff");
}
.price {
    font-family: "myFont";   /* 价格数字使用加密字体渲染 */
}
```

```html
<!-- resp.text 里的"数字"其实是乱码： -->
<span class="price">0.00</span>  <!-- 实际显示为 "99.00" -->
```

**破解思路（三步）**：

1. 下载 `.woff` 字体文件，解析出"字形码 → 真实字符"的映射表（用 `fontTools` / `ttLib` 库）；
2. 用映射表把 `resp.text` 里的乱码替换成真实字符；
3. 若每次请求字体文件都变（动态字体），需要自动解析 + 缓存映射。

```python
# 用 fontTools 读取 woff，得到 cmap（编码到字形的映射）
from fontTools.ttLib import TTFont

font = TTFont("encrypt.woff")
cmap = font.getBestCmap()
print(cmap)   # {0xe9c2: 'glyph00001', ...}
# 再结合每个 glyph 的笔画/轮廓反推真实字符（需要样本对照）
```

> 看到页面数字/价格正常、但 `resp.text` 里是乱码，第一反应就查 `@font-face` 是否引入了自定义字体。

### 5. 反爬应用：背景图文字（雪碧图/坐标位移）

有些网站把**文字或数字做进图片**里，用 CSS 背景图显示，`resp.text` 里只有一张图的位置，没有文本：

```css
/* 一个"数字表"雪碧图，通过背景偏移显示不同数字 */
.digit {
    background-image: url("https://xxx.com/captcha/num.png");
    width: 20px;
    height: 30px;
}
/* 显示第 5 个数字（背景向右偏移 -80px） */
.digit-5 { background-position: -80px 0; }
```

```html
<!-- 源码里只能看到 class，看不到数字本身 -->
<span class="digit digit-5"></span>
```

**应对思路**：

1. 下载背景图，按 `width/height` 切成一个个小图；
2. 根据 `background-position` 的偏移量定位到具体数字；
3. 用 OCR（如 `ddddocr`、`tesseract`）或模板匹配识别每个小块。

> 常见于**验证码**、**隐藏的号码/价格**。判断方法：元素尺寸固定、`background-image` 指向图片、且源码里没有对应文本。

### 6. 反爬应用：CSS content 注入文本

用伪元素 `::before/::after` 的 `content` 属性把真实文字"注入"页面，源码的 HTML 里**没有这些字**：

```html
<!-- HTML 里只有 class -->
<span class="phone"></span>
```

```css
/* 真实号码藏在 CSS 里！ */
.phone::before { content: "138-0000-"; }
.phone::after  { content: "8888"; }
```

- 页面上显示 `138-0000-8888`，但 `resp.text` 里查不到"8888"；
- 需要去对应的 CSS 文件里搜 `::before/::after` 和 `content`，把字符串拼回来。

```python
import re
import requests

css = requests.get("https://example.com/app.css").text
# 提取所有 content 值（可能用引号或转义表示）
m = re.findall(r"\.phone::(before|after)\s*\{\s*content:\s*['\"]([^'\"]*)['\"]", css)
print(m)  # [('before', '138-0000-'), ('after', '8888')]
```

> 判断方法：HTML 里有 `::before/::after` 对应 class，但元素内没有文本。数据在 CSS 而非 HTML 里，是常见的"CSS 反爬"之一。

### 7. 反爬应用：CSS 隐藏真实文字 / 用假文字遮挡

有些网站把**真实数据用 CSS 隐藏**，同时放一个"假文字"在页面上迷惑爬虫：

```css
.real { display: none; }                 /* 真实文字隐藏 */
.fake { color: red; }                    /* 假文字正常显示 */
```

```html
<span class="real">真实价格 99</span>
<span class="fake">促销价 ¥9999</span>
```

- `resp.text` 里两个都在，但页面上只显示假的；
- 判断真伪：看哪个被 `display:none` / `visibility:hidden` / 移出屏幕隐藏，**被隐藏的往往才是真实数据**。

> 与"字体加密"配套的常见组合拳：页面显示假数字 + 字体映射还原真数字，需要同时处理两处。

## 七、盒模型与布局（了解）

爬虫一般不需要，但理解布局有助于理解页面结构。

### 1. 盒模型

每个元素都是一个"盒子"，由四部分组成：

```
┌───────────────────────────┐
│         margin 外边距      │
│  ┌─────────────────────┐  │
│  │    border 边框       │  │
│  │  ┌───────────────┐  │  │
│  │  │   padding 内边距│  │  │
│  │  │ ┌───────────┐ │  │  │
│  │  │ │ content 内容│ │  │  │
│  │  │ └───────────┘ │  │  │
│  │  └───────────────┘  │  │
│  └─────────────────────┘  │
└───────────────────────────┘
```

### 2. 常用属性

```css
.box {
    width: 100px;          /* 宽 */
    height: 100px;         /* 高 */
    margin: 10px;          /* 外边距 */
    padding: 10px;         /* 内边距 */
    border: 1px solid red; /* 边框 */
    background-color: #eee; /* 背景色 */
    font-size: 14px;       /* 字号 */
    color: #333;           /* 文字颜色 */
    display: flex;         /* 弹性布局 */
}
```

### 3. 常用单位与颜色

```css
/* 长度单位 */
width: 100px;     /* 像素（最常用） */
width: 50%;       /* 相对父元素的百分比 */
font-size: 1.5em; /* 相对父元素字号的倍数 */
font-size: 1.2rem;/* 相对根元素(html)字号的倍数 */

/* 颜色写法 */
color: red;              /* 颜色关键字 */
color: #ff0000;          /* 十六进制 */
color: rgb(255, 0, 0);   /* rgb */
color: rgba(255, 0, 0, 0.5);  /* rgba，a 是透明度 */
```

### 4. display 取值速查

| 值 | 表现 |
| ---- | ---- |
| `block` | 块级，独占一行，可设宽高（div/p/h1…默认） |
| `inline` | 行内，不换行，**设宽高无效**（span/a…默认） |
| `inline-block` | 行内但可设宽高（不换行） |
| `none` | **完全隐藏**（不占位；与 `visibility:hidden` 占位隐藏不同） |
| `flex` | 弹性布局容器 |
| `grid` | 网格布局容器 |

> **爬虫视角**：`display:none` 的元素在 `resp.text` 里**仍然存在**（是 HTML 文本），只是不显示；提取时要注意区分"数据被隐藏"与"数据由 JS 生成"（后者 text 里没有）。

#### 4.1 三种"隐藏"方式的区别（反爬识别高频考点）

页面元素"看不见"不代表源码里没有。三种隐藏方式对爬虫影响完全不同：

| 方式 | 代码 | 是否占位 | 源码里是否存在 | 爬虫取文本 |
| ---- | ---- | -------- | -------------- | ---------- |
| `display:none` | `display:none` | **不占位**（元素彻底消失） | 存在 | **能取到**（text 有内容） |
| `visibility:hidden` | `visibility:hidden` | **占位**（留空白） | 存在 | 能取到 |
| `opacity:0` | `opacity:0` | **占位**（透明） | 存在 | 能取到 |
| 移出屏幕 | `text-indent:-9999px` 或 `left:-9999px` | 占位 | 存在 | 能取到 |
| JS 动态生成 | （无 CSS） | 取决于 JS | **不存在** | 取不到 |

```css
.hide-1 { display: none; }          /* 彻底不占位 */
.hide-2 { visibility: hidden; }     /* 占位但不可见 */
.hide-3 { opacity: 0; }             /* 占位且透明 */
.hide-4 { text-indent: -9999px; }   /* 移出屏幕 */
```

> **反爬判断技巧**：
> - 元素在页面上看不见、但 `resp.text` 里能搜到文字 → 多半是上面四种 CSS 隐藏之一，**文字本身可正常提取**；
> - 元素在页面上有、但 `resp.text` 里**搜不到** → 是 JS 动态生成（需渲染/找接口），**不是 CSS 问题**；
> - 两者结合：`resp.text` 里有两个"价格"，一个被 `display:none` 隐藏、一个正常显示，**被隐藏的那个往往才是真实数据**（假价格做展示）。

### 5. position 定位（了解，理解"元素在哪"）

| 值 | 参照物 | 是否脱离文档流 |
| ---- | ---- | ---- |
| `static` | 默认，正常流 | 否 |
| `relative` | 相对自己原本位置偏移 | **否**（占着原位置） |
| `absolute` | 相对**最近的、带定位（非 static）的祖先** | **是**（不占位） |
| `fixed` | 相对**浏览器视口** | 是 |
| `sticky` | 相对滚动容器，滚动到阈值后"吸住" | 特殊 |

```css
/* absolute + relative 组合定位（最常见的写法） */
.parent { position: relative; }      /* 父级作为参照物 */
.child  {
    position: absolute;
    top: 10px;
    left: 20px;
}
```

> **爬虫视角**：有些网站把真实文字定位到屏幕外（`position:absolute; left:-9999px`）或用 `z-index` 把"假文字"盖在上面做反爬；通过检查元素位置/层级可以判断哪个才是真实内容。

### 6. z-index 层级

`z-index` 决定**定位元素**谁在上层（数值越大越靠上）：

```css
.a { position: absolute; z-index: 10; }
.b { position: absolute; z-index: 1; }   /* a 在 b 之上 */
```

> 注意：`z-index` 只对**定位元素（position 非 static）或 flex 子项**生效；`float` 元素上无效。爬虫一般用不到，但分析"叠层验证码/弹层"时可参考。

### 7. 常用文本属性

```css
p {
    text-align: center;      /* 对齐：left/right/center/justify */
    line-height: 1.5;        /* 行高 */
    font-family: "微软雅黑", sans-serif;  /* 字体 */
    font-weight: bold;       /* 粗细：bold / 100~900 */
    text-indent: 2em;        /* 首行缩进 */
    text-decoration: none;   /* 下划线：underline/none */
    white-space: nowrap;     /* 不换行 */
    text-overflow: ellipsis; /* 溢出显示省略号 */
    overflow: hidden;        /* 配合上一行做"单行省略" */
}
```

## 七·五、Flex 弹性布局（高频）

现代网站（尤其是移动端适配的页面）大量使用 Flex，理解它对定位"为什么元素排成这样"很有帮助。

```html
<div class="container">
    <div class="item">1</div>
    <div class="item">2</div>
    <div class="item">3</div>
</div>
```

```css
.container {
    display: flex;                 /* 开启弹性布局 */
    justify-content: space-between;/* 主轴对齐：start/center/space-between/space-around */
    align-items: center;           /* 交叉轴对齐：center/flex-start/flex-end */
    flex-wrap: wrap;               /* 换行 */
}

.item {
    flex: 1;                       /* 等分剩余空间 */
}
```

> 爬虫中常看到"列表/卡片"用 flex 布局，只要标签层级是 `.container > .item` 结构，用 `container 里的 item` 这种选择器就能批量定位。

## 七·五·五、Grid 网格布局（了解）

Grid 是二维布局（行列同时控制），比 Flex 更适合"宫格类"页面（如商品墙、图片墙）：

```css
.container {
    display: grid;                                    /* 开启网格 */
    grid-template-columns: 1fr 1fr 1fr;               /* 3 列，等宽 */
    grid-template-rows: 100px 100px;                  /* 2 行，高 100px */
    gap: 10px;                                        /* 行列间距 */
}

/* 用区域命名更直观 */
.container {
    grid-template-areas:
        "header header header"
        "menu   main   aside"
        "footer footer footer";
}
```

| 属性 | 作用 |
| ---- | ---- |
| `grid-template-columns` | 定义列：`100px 1fr 2fr` / `repeat(3, 1fr)` |
| `grid-template-rows` | 定义行 |
| `gap` / `row-gap` / `column-gap` | 间距 |
| `grid-template-areas` | 区域命名布局 |
| `justify-items` / `align-items` | 单元格内对齐 |

> **爬虫视角**：Grid 只是"排版方式"，不影响 HTML 结构和 xpath/bs4 定位；看到 `display:grid` 说明是规则网格，一般可直接用"父容器内同一层级"的选择器批量提取。

## 七·六、响应式与媒体查询

网站会针对不同屏幕宽度展示不同样式。媒体查询 `@media` 是最常见手段：

```css
/* 屏幕宽度 ≥ 768px 时生效（桌面） */
@media (min-width: 768px) {
    .box { width: 50%; }
}

/* 屏幕宽度 ≤ 767px 时生效（手机） */
@media (max-width: 767px) {
    .box { width: 100%; }
}
```

> 爬虫视角：手机端页面（`m.xxx.com`）往往结构更简单、反爬更弱，很多爬虫优先抓手机版。

## 七·八、scrapy CSS 选择器进阶（爬虫必会）

普通 CSS 不能取文本，scrapy 扩展了 `::text` 和 `::attr()`：

```python
import scrapy

def parse(self, response):
    # ::text 取文本
    title = response.css("h1.title::text").get()

    # ::attr(属性) 取属性
    href = response.css("a.name::attr(href)").get()

    # :contains 包含文本
    link = response.css("a:contains('下一页')").get()

    # 多条件组合
    item = response.css("div.item[data-type='goods']")
```

| 写法 | 含义 |
| ---- | ---- |
| `div.item` | class 为 item 的 div |
| `div#main` | id 为 main 的 div |
| `div > p` | div 的直接子 p |
| `div p` | div 内所有 p |
| `a::text` | 取 a 的文本 |
| `a::attr(href)` | 取 a 的 href 属性 |
| `li:nth-child(2)` | 第 2 个 li |
| `[data-id='100']` | 属性等于某值 |

### CSS 选择器 ↔ XPath 对照表（互相转换）

爬虫里 CSS 选择器和 XPath 可以混用，掌握对照关系能灵活切换：

| 需求 | CSS 选择器 | XPath |
| ---- | ---------- | ----- |
| 按标签 | `div` | `//div` |
| 按 class | `.item` | `//*[@class='item']` 或 `//div[@class='item']` |
| 按 id | `#main` | `//*[@id='main']` |
| 后代（任意层级） | `div p` | `//div//p` |
| 子元素（一层） | `div > p` | `//div/p` |
| 属性存在 | `[href]` | `//*[@href]` |
| 属性等于 | `[type='text']` | `//*[@type='text']` |
| 属性包含 | `[class*='item']` | `//*[contains(@class,'item')]` |
| 取文本 | `a::text` | `a/text()` |
| 取属性 | `a::attr(href)` | `a/@href` |
| 第 n 个子元素 | `li:nth-child(2)` | `//li[2]` |

> 提示：xpath 的 `//div[contains(@class, "item")]` 对应 CSS 的 `div[class*="item"]`；但注意 `class="item active"` 这种多 class 时，xpath 直接 `@class='item'` 会匹配失败，要用 `contains(@class,'item')`，而 CSS 的 `.item` 天然支持多 class。

## 八、小结

- CSS 由"选择器 + 声明块"组成；
- 三种引入方式：内联、内部、外部（推荐）；
- 最常用选择器：**标签选择器、类选择器（.）、ID 选择器（#）、后代选择器（空格）、属性选择器（[attr=val]）**；
- 进阶高频选择器：子选择器 `>`、`nth-child` / `nth-of-type`、伪类 `:hover`、伪元素 `::before/::after`；高级伪类 `:is()` / `:where()` / `:has()`（`li:has(.price)` 定位父容器）；
- 优先级：`!important > 内联 > ID > 类 > 标签`，同权重后写生效；`:where()` 权重为 0；
- 布局：盒模型（margin/border/padding/content）、`display` 取值（block/inline/none/flex/grid）、**Flex 弹性布局**、**Grid 网格布局**、媒体查询 `@media`；
- 定位与层级：`position` 五种取值（static/relative/absolute/fixed/sticky）、`z-index`；理解"元素被隐藏/偏移"可辅助判断反爬；
- 在爬虫中，CSS 选择器是定位数据的核心工具，与 xpath 同样重要，二者可以互相转换使用；scrapy 中用 `::text`、`::attr()` 取值；
- 反爬相关：CSS 隐藏（`display:none`、移出屏幕）与 **@font-face 字体加密**（页面正常、源码乱码时优先排查）；**背景图文字**（雪碧图 + `background-position` 偏移识别）、**CSS content 注入文本**（`::before/::after` 里藏真数据）、**隐藏真字/放假字**（被隐藏的往往才是真数据）；
- **三隐藏方式对比**：`display:none`（不占位）/ `visibility:hidden`（占位）/ `opacity:0`（透明）源码里都存在、都能取到文本；源码搜不到才是 JS 生成的；
- 伪类补充：`:not()` 排除、`:nth-child(odd/even/3n+1)` 规律选择、`:first/last-of-type`、`:empty`、`:only-child`；
- 引入方式补充：`<link>` 与 `@import` 的区别；CSS 选择器 ↔ XPath 对照表。

> 更多选择器参考：[w3school CSS 选择器](https://www.w3school.com.cn/cssref/css_selectors.asp)
