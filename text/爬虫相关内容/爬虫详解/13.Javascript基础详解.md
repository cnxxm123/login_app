# JavaScript 基础 详解

## 一、为什么爬虫要学 JavaScript？

现代网站大量使用 JavaScript 实现**动态渲染**和**数据加密**：

- 数据通过 AJAX 异步加载，HTML 源码里没有；
- 请求参数被 JS 加密（如 MD5、AES、RSA）；
- Cookie 由 JS 动态生成。

因此，做 **JS 逆向**必须先掌握 JavaScript 基础语法。

> JS 官方文档（MDN）：https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference

## 二、如何在 HTML 中引入 JS

### 方案一：直接在 script 标签中写 JS

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Document</title>
</head>
<body>
    <script>
        console.log("你好，JavaScript");
    </script>
</body>
</html>
```

### 方案二：引入外部 JS 文件

```html
<head>
    <!-- 通过 script 的 src 引入 js 文件 -->
    <script src="app.js"></script>
</head>
```

> **注意**：HTML 是从上到下渲染的。`<script>` 放在 `<head>` 里会在页面内容加载前执行，放在 `</body>` 前则在内容加载后执行。通常建议把依赖 DOM 的脚本放在 body 末尾。

## 三、JavaScript 基本数据类型

| 类型 | 说明 | 示例 |
| ---- | ---- | ---- |
| `number` | 数字（整数、小数都是 number） | `10`, `3.14` |
| `string` | 字符串（单引号/双引号） | `'hello'`, `"world"` |
| `boolean` | 布尔值（**小写** true/false） | `true`, `false` |
| `object` | 对象（所有 new 出来的都是对象） | `{}`, `[]`, `new Date()` |
| `function` | 函数类型 | `function(){}` |
| `undefined` | 未定义（未赋值的变量默认值） | `undefined` |

> `typeof null` 的结果是 `"object"`（历史遗留 bug），`typeof` 对数组也返回 `"object"`。判断数组要用 `Array.isArray()`。

### 0. typeof 类型判断（重点）

用 `typeof` 可以判断变量的数据类型，逆向时常用它来"猜"加密函数参数的类型：

```js
console.log(typeof 10);        // "number"
console.log(typeof "abc");     // "string"
console.log(typeof true);      // "boolean"
console.log(typeof undefined); // "undefined"
console.log(typeof function(){}); // "function"
console.log(typeof null);      // "object"（历史遗留 bug，注意！）
console.log(typeof [1,2,3]);   // "object"（数组也是对象）
console.log(typeof {});        // "object"
```

判断数组要这样写：

```js
var arr = [1, 2, 3];
console.log(Array.isArray(arr));   // true
console.log(arr instanceof Array); // true
```

### 1. 声明变量

```js
var a;                // 创建变量，未赋值（值为 undefined）

var e, f = 5;         // 只给 f 赋值
```

> 现代开发推荐使用 `let`（块级作用域、不能重复声明）和 `const`（常量），详见"JS 进阶"。

### 2. 注释

```js
// 单行注释
/* 多行注释 */
```

### 3. 运算符

```js
var a = 10, b = 20, c = 30;

// 与 Python 的区别：and/or/not 换成 &&、||、!
console.log(a > b && b > c);   // false
console.log(!(a > b));          // true
console.log(a < b || b > c);    // true
```

### 4. `==` 和 `===`（重点）

- `==`：只比较**值**是否相等（会做类型转换）；
- `===`：同时比较**类型**和**值**。

```js
var a = "123";
var b = 123;
console.log(a == b);    // true（"123" 被转成数字 123）
console.log(a === b);   // false（类型不同：string vs number）
```

> 逆向分析时，务必注意网站用的是 `==` 还是 `===`，直接复制时不要随意改动，否则逻辑可能不同。

### 5. 位运算（逆向超重点）
JS 位运算操作的是**二进制位**，逆向加密代码里**大量出现**（加密、校验、哈希计算都会用）：

| 运算符 | 含义 | 示例 |
| ------ | ---- | ---- |
| `&` | 按位与 | `5 & 3` → `1` |
| `\|` | 按位或 | `5 \| 3` → `7` |
| `^` | 按位异或（**最常用**） | `5 ^ 3` → `6` |
| `~` | 按位取反 | `~5` → `-6` |
| `<<` | 左移（相当于 ×2^n） | `1 << 4` → `16` |
| `>>` | 右移（相当于 ÷2^n） | `16 >> 2` → `4` |
| `>>>` | 无符号右移 | `-1 >>> 0` → `4294967295` |

```js
// 按位异或：最常用于"加密/还原"
// 规律：a ^ b ^ b === a（异或两次还原原值）
console.log(5 ^ 3);      // 6
console.log(6 ^ 3);      // 5（还原！）
console.log(0 ^ 123);    // 123
console.log(255 ^ 0xff); // 0（十六进制写法）

// 左移 / 右移：相当于乘除 2 的幂
console.log(1 << 4);    // 16  （1 * 2^4）
console.log(16 >> 2);   // 4   （16 / 2^2）

// 取最低位 / 奇偶判断
console.log(5 & 1);     // 1（奇数）
console.log(4 & 1);     // 0（偶数）
```

> **逆向还原技巧**：当看到 `a = b ^ key` 这种异或加密时，用同样的 `key` 再异或一次就能还原明文。常见的"异或加密"本质就是 `明文 ^ 密钥`。

### 6. 逻辑运算符的"短路"行为（重点）

`&&`、`||`、`!` 不只返回布尔值，还能返回**某个操作数本身**，逆向代码里经常用这个特性做"判空/兜底"：

```js
// ||：左边为真返回左边，左边为假返回右边（常用于给默认值）
var name = "" || "默认名";
console.log(name);          // "默认名"
var num = 0 || 10;
console.log(num);           // 10（0 是假值）

// &&：左边为假返回左边，左边为真返回右边
var a = 1 && 2;
console.log(a);             // 2
var b = 0 && 2;
console.log(b);             // 0

// 常见用法：防止 undefined 报错
var obj = null;
// console.log(obj.name);  // 报错！
console.log(obj && obj.name); // 不报错，返回 null

// 结合三元运算符
var age = 18;
var tip = age >= 18 ? "成年" : "未成年";
console.log(tip);           // "成年"
```

> 假值列表（在布尔判断中为 false 的 6 个值）：`false`、`0`、`""`（空串）、`null`、`undefined`、`NaN`。其余都是真值（包括空数组 `[]`、空对象 `{}`！）。

### 7. 数据类型转换（补充）

```js
// string -> number：parseInt
var a = "10086";
a = parseInt(a, 10);        // 转成整数，第二个参数是进制（默认 10）
console.log(a + 10);        // 10096

// number -> string：toString() 或 + ""
var b = 100;
console.log(b.toString());  // "100"
console.log(b + "");        // "100"

// 进制转换
var m = 122;
console.log(m.toString(16));   // "7a"（转 16 进制）
console.log(parseInt("AB", 16)); // 171（16 进制字符串转十进制）
```

### 6. 自增/自减 `++` / `--`

```js
a++;    // 相当于 a = a + 1
++a;    // 相当于 a = a + 1
a--;    // 相当于 a = a - 1
--a;    // 相当于 a = a - 1
```

> 区别：`a++` 是**先返回旧值再自增**；`++a` 是**先自增再返回新值**。

```js
var x = 5;
console.log(x++);   // 5（先输出旧值）
console.log(x);     // 6
var y = 5;
console.log(++y);   // 6（先自增再输出）
```

### 9. 字符串操作

```js
var s = "Hello World";

s.split(",")            // 字符串切割，返回数组
s.substring(start, end) // 切片：从 start 到 end（不含 end）
s.length                // 字符串长度
s.charAt(i)             // 第 i 个字符，等价于 s[i]
s.indexOf("World")      // 第一次出现位置的索引，没有则返回 -1
s.lastIndexOf("o")      // 最后一次出现位置的索引
s.toUpperCase()         // 转大写
s.toLowerCase()         // 转小写
s.startsWith("He")      // 是否以 xxx 开头
s.charCodeAt(0)         // 某个位置的字符的 ASCII 码
String.fromCharCode(97) // 由 ASCII 码还原成字符 "a"
```

**更多高频字符串方法**（逆向里也经常出现）：

```js
s.trim()                 // 去掉首尾空格
s.includes("World")      // 是否包含某子串（返回布尔）
s.replace("World", "JS") // 替换第一个匹配（注意：只替换第一个！）
s.replaceAll("o", "0")   // 替换全部匹配（ES2021）
s.repeat(3)              // 重复拼接 3 次
s.slice(start, end)      // 切片（类似 substring，但支持负数索引）
s.concat("!", "!")       // 拼接字符串，返回新字符串
s.padStart(8, "0")       // 前面补 "0" 补到长度 8（加密补零常见）
s.padEnd(8, "0")         // 后面补 "0"
s.charCodeAt(0)          // 取第一个字符的 unicode 码
```

> **字符串是不可变的**：任何"修改"操作（replace、slice 等）都返回**新字符串**，原字符串不变。逆向时看到 `s = s.replace(...)` 是在重新赋值。

### 10. null 与 undefined

- `null`：空对象（主动设置的"什么都没有"）；
- `undefined`：空变量（声明了但没赋值）。

两者都表示"空"，在布尔判断中都当作 `false`。

```js
var a = null;
var b;              // undefined
if (!a) { console.log("a 是假的"); }
if (!b) { console.log("b 也是假的"); }
```

### 11. 数字相关（Number / Math）

加密代码里经常会做时间戳、随机数、取整、进制转换，掌握这些方法：

```js
// 数值转换
parseInt("12.9");       // 12（取整数部分）
parseFloat("3.14abc");  // 3.14
Number("123");          // 123
Number(true);           // 1
+ "123";                // 123（一元加号也能转数字）
~~3.9;                  // 3（双重按位取反 = 取整，逆向常见）

// 判断
isNaN("abc");           // true（不是数字）
isNaN("123");           // false
Number.isNaN(NaN);      // true（更严格）
isFinite(10);           // true

// Math 对象（重点）
Math.random();          // [0,1) 随机数
Math.floor(3.9);        // 3  向下取整
Math.ceil(3.1);         // 4  向上取整
Math.round(3.5);        // 4  四舍五入
Math.abs(-5);           // 5
Math.max(1, 3, 2);      // 3
Math.min(1, 3, 2);      // 1
Math.pow(2, 10);        // 1024（2 的 10 次方）
Math.sqrt(9);           // 3
Math.PI;                // 3.14159...
Math.floor(Math.random() * 100); // 0~99 随机整数（加密常用）

// 生成指定范围随机数（滑块轨迹常用）
function rand(min, max) {
    return Math.floor(Math.random() * (max - min + 1)) + min;
}
```

### 12. 异常处理 try / catch（逆向高频）

逆向加密代码里常见 `try...catch` 包裹核心逻辑（一旦解密失败就降级或提示），必须能看懂：

```js
try {
    // 可能出错的代码
    var x = JSON.parse("不是json");
} catch (e) {
    // 出错后执行
    console.log("出错啦：", e.message);
} finally {
    // 无论对错都会执行（常用于清理、计数）
    console.log("一定会执行");
}
```

**常见逆向场景**：

```js
// 1) 解密失败时返回空
function decrypt(data) {
    try {
        var obj = JSON.parse(data);
        return obj.sign;
    } catch (e) {
        return "";
    }
}

// 2) 无限 debugger 的 try-catch 变体（判断是否调试）
//    （原理：被调试时 debugger 触发异常，进入 catch 分支）
(function() {
    function ccc() {
        try {
            (function() { debugger; })();
        } catch (e) {
            console.log("正常执行");
        }
        setTimeout(ccc, 1000);
    }
    // ccc();
})();

// 3) throw 主动抛异常（有些网站在环境检测失败时主动抛错）
function check() {
    if (typeof window === "undefined") {
        throw new Error("环境错误");
    }
    return true;
}
```

## 五、循环语句

### 1. while / do-while

```js
// while：先判断再执行
while (条件) {
    循环体;   // 可使用 break / continue
}

// do-while：先执行一次再判断，至少执行一次
do {
    循环体;
} while (条件);
```

### 2. for（重点）

```js
// 语法：for(表达式1; 表达式2; 表达式3){ 循环体 }
// 执行顺序：
//   ① 执行表达式1（初始化）
//   ② 判断表达式2（条件），为真则执行循环体
//   ③ 执行表达式3（步进）
//   ④ 回到② ...
for (var i = 1; i < 100; i++) {
    console.log(i);      // 打印 1~99
}
```

### 3. for...in（遍历索引）

```js
var a = [11, 22, 33, 44, 55, 66];
for (let i in a) {
    console.log(i + "_" + a[i]);   // i 是索引，a[i] 才是数据
}
```

### 4. for...of（遍历元素）

```js
for (let x of a) {
    console.log(x);    // 直接拿到元素
}
```

### 5. break / continue / 标签（重点）

```js
// break：跳出整个循环
for (var i = 0; i < 10; i++) {
    if (i === 3) break;
    console.log(i);      // 0 1 2
}

// continue：跳过本次循环，继续下一次
for (var i = 0; i < 5; i++) {
    if (i === 2) continue;
    console.log(i);      // 0 1 3 4
}

// 标签（label）：跳出多层嵌套循环（逆向代码偶尔出现，比较难懂）
outer:
for (var i = 0; i < 3; i++) {
    for (var j = 0; j < 3; j++) {
        if (i === 1 && j === 1) break outer;  // 直接跳出最外层
        console.log(i, j);
    }
}
// 输出：0 0 / 0 1 / 0 2 / 1 0 就结束了
```

> `break` 只能跳出**当前**循环，想跳出多层必须用**标签**。遇到 `xxx:` 冒号开头的写法（如 `outer:`），它就是标签。

### 6. while 里的坑：与 Python 的区别

```js
// Python 里没有 do-while；JS 的 do-while 至少执行一次
var n = 0;
do {
    console.log(n);   // 0（即使条件不成立，也先执行一次）
    n++;
} while (n < 0);

// while 判断"非 0 / 非空"等真值
var i = 10;
while (i) {           // 10 是真值，一直减到 0（0 是假值）停止
    i--;
}
console.log(i);       // 0
```

## 六、数组和对象

### 1. 数组

```js
var as = [11, 22, 33, 44, 55];       // 字面量
var bs = new Array(11, 22, 33);      // 构造函数（效果一样）
```

常用操作：

```js
arr.length;             // 数组长度
arr.push(data);         // 尾部添加
arr.unshift(data);      // 头部添加
arr.pop();              // 尾部删除并返回
arr.shift();            // 头部删除并返回
arr.join("连接符");      // 用连接符拼接成字符串
arr.slice(start, end);  // 切片
arr.indexOf(val);       // 查找元素索引
arr.reverse();          // 反转
```

### 2. 对象（对标 Python 字典）

```js
var p = {
    name: "汪峰",       // key 可以省略引号
    "age": 18,
    wife: "章子怡",
    chi: function () {  // 对象里可以放函数（方法）
        console.log("吃饭");
    }
};

// 访问
console.log(p.name);     // 汪峰
console.log(p["age"]);   // 18
p.chi();                 // 调用方法
p["chi"]();
```

遍历对象（跳过函数类型）：

```js
for (var n in p) {
    if (typeof (p[n]) != "function") {
        console.log(p[n]);
    }
}
```

### 3. 数组的更多常用方法

```js
var arr = [3, 1, 4, 1, 5];

arr.sort();               // 排序（默认按字符串排序！）
arr.sort((a, b) => a - b) // 数字升序排序（重点：数字排序必须传比较函数）
arr.concat([6, 7])        // 拼接返回新数组
arr.includes(4)           // 是否包含（返回布尔）
arr.find(x => x > 3)      // 找到第一个满足条件的元素
arr.filter(x => x > 2)    // 过滤出所有满足条件的元素，返回新数组
arr.reduce((s, x) => s + x, 0)   // 累加，返回一个值
arr.every(x => x > 0)     // 是否全部满足
arr.some(x => x > 4)      // 是否至少一个满足
```

> 逆向分析时经常遇到 `sort`、`filter`、`reduce` 处理加密参数，注意 `sort` 默认按**字符串**排序，数字排序必须传 `(a, b) => a - b`。

**数组去重 / 复制（逆向高频）**：

```js
// 数组去重：Set + 展开运算符
var arr = [1, 2, 2, 3, 3, 3];
var uniq = [...new Set(arr)];
console.log(uniq);        // [1, 2, 3]

// 浅拷贝（只复制一层）
var arr2 = arr.slice();           // 方式一
var arr3 = [...arr];              // 方式二
console.log(arr2);                // [3, 1, 4, 1, 5]

// 深拷贝（复制所有层级，防止互相影响）
var nested = { a: { b: 1 } };
var deepCopy = JSON.parse(JSON.stringify(nested));
deepCopy.a.b = 999;
console.log(nested.a.b);          // 1（原对象不受影响）

// splice：增删改（splice 会直接修改原数组！）
var arr = [1, 2, 3, 4, 5];
arr.splice(1, 2);         // 从索引 1 开始删 2 个 → [1, 4, 5]
arr.splice(1, 0, "新");   // 在索引 1 插入 → [1, "新", 4, 5]
```

> **浅拷贝 vs 深拷贝**：`slice`/`...` 只复制第一层；里面若还有对象/数组，还是共享引用。逆向处理加密数据（含嵌套对象）时若看到 `JSON.parse(JSON.stringify(x))`，就是标准的深拷贝写法。

### 4. forEach 与 map

```js
var arr = ["吃瓜", "我爱你", "我恨你", "还我钱"];

// forEach：遍历，不返回新数组
arr.forEach(function (e, t) {
    console.log(e, t);   // e 是数据，t 是索引
});

// map：遍历并返回新数组
var r = arr.map(function (e, t) {
    return e + t;
});
console.log(r);
```

### 5. JSON 转换

```js
// 对象 -> JSON 字符串（"对象转 json 先转字符串"）
var jsonStr = JSON.stringify({name: "alex", age: 18});
console.log(jsonStr);    // {"name":"alex","age":18}

// JSON 字符串 -> 对象
var obj = JSON.parse(jsonStr);
console.log(obj.name);   // alex
```

> **JSON 是 JS 逆向的"情报中枢"**：加密前的明文、加密后的密文往往都通过 `JSON.stringify` 生成。在控制台 Hook 住 `JSON.stringify` 和 `JSON.parse`，就能抓到加密前后数据（详见进阶文件中的 Hook 章节）。

## 七、ES6 常用新特性（逆向代码高频）

### 1. let / const（重点）

| 关键字 | 作用域 | 能否重复声明 | 能否修改 |
| ------ | ------ | ------------ | -------- |
| `var` | 函数级 | 能 | 能 |
| `let` | 块级 `{}` | 不能 | 能 |
| `const` | 块级 `{}` | 不能 | **不能**（常量） |

```js
const PI = 3.14;
PI = 3;        // 报错！常量不可修改

{
    let a = 10;
    var b = 20;
}
console.log(b);   // 20（var 是函数级，出了块还能用）
console.log(a);   // 报错！let 是块级，出了块就没了
```

> 现代网站加密 JS 大量使用 `let/const`，逆向时注意区分：`const` 声明的加密密钥等常量不会在运行中被修改。

### 2. 模板字符串（反引号）

```js
var name = "alex";
var age = 18;

// 拼接字符串，${} 里放变量或表达式
var s = `我的名字是${name}, 今年${age}岁`;
console.log(s);   // 我的名字是alex, 今年18岁

// 相比 + 拼接更清晰
var s2 = "我的名字是" + name + ", 今年" + age + "岁";
```

> 逆向代码中常见 `${xxx}` 拼 URL、拼参数，看到反引号要能反应过来这是模板字符串。

### 3. 解构赋值

```js
// 数组解构
var [a, b, c] = [1, 2, 3];
console.log(a, b, c);   // 1 2 3

// 对象解构
var {name, age} = {name: "alex", age: 18};
console.log(name, age);   // alex 18

// 交换变量
var x = 1, y = 2;
[x, y] = [y, x];
console.log(x, y);   // 2 1
```

### 4. 展开运算符（...）

```js
var arr1 = [1, 2, 3];
var arr2 = [0, ...arr1, 4];   // 把数组"展开"进新数组
console.log(arr2);            // [0, 1, 2, 3, 4]

var obj1 = {name: "alex"};
var obj2 = {...obj1, age: 18};   // 对象合并
console.log(obj2);               // {name: 'alex', age: 18}

// 函数接收不定参数
function f(...args) {
    console.log(args);   // [1, 2, 3]
}
f(1, 2, 3);
```

> 逆向代码里经常用展开运算符复制对象/数组合并参数，理解 `...` 的含义即可。

## 八、函数（重点：函数也是变量）

### 1. 声明与调用

```js
function 函数名(形参1, 形参2) {
    函数体;
    return 返回值;
}

函数名(实参1, 实参2);   // 调用
```

```js
function an(a, b) {
    return a + b;
}
var ret = an(1, 2);
console.log(ret);   // 3
```

### 2. 函数自运行（逆向高频）

JS 语法不严格，只要 `xxx()` 中 xxx 是函数就能执行：

```js
// 常见自运行写法
(function(){})();
!function(){}();
~function(){}();
-function(){}();

// 带参自运行
(function (a, b) {
    return a + b;
})(1, 2);

// 自运行返回对象（模块化）
var m = (function () {
    return {
        name: "alex",
        age: "18",
    };
})();
console.log(m.name);   // alex
```

### 3. 匿名函数赋值给变量

```js
var fn = function () {
    console.log("我是匿名函数");
};
fn();
```

### 4. 逗号表达式的返回值

```js
var an = function () {
    return console.log("我爱你"), console.log("爱你妹"), "哈哈";
};
// 返回语句中每个表达式都会执行，但真正的返回值是最后一个："哈哈"
```

### 5. 函数的参数数量（arguments）

JS 函数允许传入任意数量的参数，多余的参数都会进入 `arguments`（类数组对象）：

```js
function fn() {
    for (var i = 0; i < arguments.length; i++) {
        console.log(arguments[i]);
    }
}

fn();          // 无参数
fn(1, 2, 3);   // 依次打印 1 2 3
```

> 逆向时，加密函数常常是"参数个数不定"，用 `arguments` 逐个取出参数分析。

### 6. 函数提升 vs 函数表达式（重点区别）

```js
// 函数声明：会被"提升"，可以在声明之前调用
sayHi();                    // 正常输出
function sayHi() {
    console.log("你好");
}

// 函数表达式：不会提升，声明之前调用会报错
// bye();                  // 报错！bye 还是 undefined
var bye = function () {
    console.log("再见");
};
bye();                      // 正确
```

### 7. 回调函数（callback）

把函数作为参数传给另一个函数，就是回调函数。逆向代码里 AJAX 成功/失败处理大量使用：

```js
function request(url, successCallback) {
    console.log("请求 " + url);
    // 模拟请求完成后调用回调
    successCallback("返回的数据");
}

// 传入一个匿名函数作为回调
request("/api/data", function (data) {
    console.log("收到数据：" + data);
});

// 数组方法就是回调的典型：map 的 () => {} 就是回调
var arr = [1, 2, 3];
var newArr = arr.map(function (x) { return x * 2; });
console.log(newArr);        // [2, 4, 6]
```

### 8. this 指向（基础概念）

`this` 的指向取决于**调用方式**，逆向代码里经常出现，先记住最简单的规律：

```js
// 1) 直接调用 → this 是 window（全局）
function show() {
    console.log(this);      // window
}
show();

// 2) 作为对象方法调用 → this 是对象本身
var p = {
    name: "alex",
    say: function () {
        console.log(this.name);   // alex
    }
};
p.say();

// 3) 作为构造器（new）调用 → this 是新创建的对象
function People(name) {
    this.name = name;       // this 指向新对象
}
var p1 = new People("张三");
console.log(p1.name);       // 张三

// 4) 箭头函数没有自己的 this，继承外层 this
var obj = {
    name: "李四",
    fn: function () {
        var f = () => console.log(this.name);
        f();                // 李四（箭头函数沿用外层 this）
    }
};
obj.fn();
```

> 逆向分析 `this` 的三步：① 看函数怎么被调用（`x.y()` 则 this 是 x）；② 是否 `new`；③ 是否被 `call/apply/bind` 指定过（见进阶文件）。

## 九、小结

- 数据类型：number / string / boolean / object / function / undefined；用 `typeof` 判断类型（`typeof null === "object"` 是坑）；
- `==` 只比值、`===` 比类型和值（逆向注意）；**位运算**（`^ & << >>`）和**异或加密**是逆向核心；
- 逻辑运算会"短路"：`a || b` 常用于给默认值，`a && b` 常用于防报错；6 个假值要牢记；
- 变量推荐 `let`（块级作用域）；字符串操作、数组（去重/深拷贝）、对象、JSON 转换是高频；
- `try/catch/finally` 异常处理、`Math`/`Number` 取整与随机数、`break/continue/标签` 要会看；
- ES6 新特性：`let/const`、模板字符串（反引号）、解构赋值、展开运算符 `...`，逆向代码中大量出现；
- 函数是变量：函数提升 vs 函数表达式、匿名函数、自运行函数 `(function(){})()`、`arguments`、回调函数、`this` 指向都是 JS 逆向的必备知识。
