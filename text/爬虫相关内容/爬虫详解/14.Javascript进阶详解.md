# JavaScript 进阶 详解

## 一、变量提升（var 的问题）

JavaScript 在执行代码前会先做"预编译"：把 `var` 声明的变量**提升**到作用域顶部（只提升声明，不提升赋值）。

```js
function fn() {
    console.log(name);   // undefined（变量提升了，但赋值没提升）
    var name = "大马猴";
}
fn();
```

实际运行时等价于：

```js
function fn() {
    var name;            // 声明被提升到这里
    console.log(name);   // undefined
    name = "大马猴";      // 赋值留在原地
}
```

### 用 let 解决

ES6 中推荐用 `let` 声明变量，**没有变量提升**，且**同一个作用域内不能重复声明**：

```js
function fn() {
    console.log(name);   // 直接报错（let 不提升）
    let name = "大马猴";
}
fn();
```

```js
// var 可以重复声明（不合理）
var name = "周杰伦";
var name = "王力宏";    // 合法，覆盖

// let 同一作用域只能声明一次
let name = "周杰伦";
let name = "王力宏";    // 报错！
```

**结论**：

1. 用 `let` 声明变量是新版 JS 提倡的方式；
2. 同一个作用域内，`let` 变量只能声明一次。

## 二、闭包函数（重点）

### 1. 全局变量污染的危害

JS 里函数内部可以直接修改外部变量，这导致**全局变量非常不安全**：

```js
let name = "周杰伦";
function chi() {
    name = "吃掉";      // 直接改掉了全局变量
}
chi();
console.log(name);      // "吃掉"
```

> 在 Python 中，函数内的同名变量是局部变量，要改全局必须用 `global`。JS 里不加声明直接赋值就是改全局。

### 2. 用 IIFE 隔离作用域

两个 JS 文件如果在同一个页面运行，它们共享全局作用域，变量会互相污染。用**立即执行函数（IIFE）** 创建独立作用域：

```js
// 1号工具人
(function () {
    var name = "alex";
    setTimeout(function () {
        console.log("一号工具人:" + name);   // alex
    }, 1000);
})();

// 2号工具人
(function () {
    var name = "周杰伦";
    console.log("二号工具人:", name);         // 周杰伦
})();
```

两个文件各自有独立的 `name`，互不干扰。

### 3. 闭包：既要隔离，又要对外暴露功能

外面的代码需要调用内部的功能怎么办？——**返回函数/对象**，这就是闭包的本质：**函数内部持有外部（或自己的）私有变量，并通过返回的函数/对象对外提供服务，形成一个封闭、自洽的环境。**

```js
// 1号工具人：封装一个加密模块
let jiami = (function () {

    let key = "10086";       // 私钥，外部无法直接访问

    // 内部私有函数，外界无法访问
    let n = {
        abc: function () {
            console.log("我是 abc");
        }
    };

    // 对外暴露的功能
    return {
        rsa_jiami: function (data) {
            console.log("秘钥:" + key);
            n.abc();
            console.log("数据:" + data);
            return "我要返回密文";
        },
        get_rsa_key: function () {
            return this.rsa_key = "rsa的key", this.rsa_key;
        }
    };
})();

// 使用
let miwen = jiami.rsa_jiami("吃你的糖葫芦吧");
console.log(miwen);
```

> **闭包三要素**：① 函数内定义私有变量；② 返回一个能访问这些私有变量的函数/对象；③ 外部只能通过返回的接口操作，内部状态被"锁"在闭包中。
>
> 现实中加密 JS 包就是这么写的：内部藏算法和密钥，只暴露 `encrypt`/`decrypt` 等少数接口。逆向时，我们就是通过分析这些暴露的接口和闭包内的算法来还原逻辑。

## 四、定时器

### 1. setTimeout —— 延时执行（非阻塞）

```js
// 语法：t = setTimeout(函数, 毫秒, [参数...])
var t = setTimeout(function () {
    console.log("我爱你");
```

### 2. setInterval —— 间隔执行（无限 debugger 的来源）

```js
// 语法：t = setInterval(函数, 毫秒)
var t = setInterval(function () {
    console.log("我爱你");
}, 5000);              // 每隔 5 秒执行一次

window.clearInterval(t);   // 停止定时器

// 清理掉所有定时器（反"无限 debugger"用）
for (let i = 0; i <= 9999; i++) {
    window.clearInterval(i);
}
```

## 七、prototype 原型链（超重点）

### 1. 构造函数

JS 中的 `function` 除了当普通函数，还能**当构造函数**（构造对象时，函数名通常首字母大写）：

```js
function People(name, age) {
    this.name = name;
    this.age = age;
    this.run = function () {
        console.log(this.name + "在跑");
    };
}

var p1 = new People("张三", 18);
var p2 = new People("李四", 19);
p1.run();
p2.run();
```

### 2. prototype：动态给"类"添加方法

如果每个对象都在构造函数里定义方法，每 new 一个对象就复制一份方法，太臃肿。用 `prototype` 把方法挂到原型上，所有实例共享：

```js
function People(name, age) {
    this.name = name;
    this.age = age;
}
// 通过 prototype 给 People 增加方法（所有实例共享）
People.prototype.xxoo = function () {
    console.log(this.name + "还可以xxoo");
};

var p1 = new People("张三", 18);
var p2 = new People("李四", 19);
p1.xxoo();   // 张三还可以xxoo
p2.xxoo();   // 李四还可以xxoo
```

### 3. 构造器 constructor

```js
function People() {}

var p = new People();
p.constructor === People;    // true（constructor 指向构造函数）
```

### 4. 原型对象 `__proto__`

每个对象都有隐藏属性 `__proto__`，指向它的**原型对象**。

查找方法/属性时：**先找对象自己 → 没有就找原型对象 → 再没有继续向上找**。

```js
function Friend() {
    this.chi = function () {
        console.log("我的朋友在吃");
    };
}
Friend.prototype.chi = function () {
    console.log("我的原型在吃");
};

var f = new Friend();
f.chi();   // "我的朋友在吃"（优先用对象自己的方法）

// 构造器的 prototype 和实例的 __proto__ 指向同一个对象
f.__proto__ === Friend.prototype;   // true
```

### 5. 原型链

原型对象也是对象，它也有 `__proto__`，层层向上直到 `Object.prototype`：

```js
f.__proto__.__proto__ === Object.prototype;   // true
```

执行 `f.toString()` 时，查找路径：`f` → `f.__proto__`（Friend.prototype）→ `f.__proto__.__proto__`（Object.prototype，这里有 toString）→ 找到执行。

**原型链就是 JS 方法查找的路径指示标**。如果一路找到 `Object.prototype` 都没有，就报错：

```js
f.hahahahahahah();   // 报错：不存在该方法
```

### 6. 用原型链反"无限 debugger"

先看现象：`(function(){debugger})();` 会让页面不断进入断点。

原理：**每个函数都是 `Function` 的对象**，函数通过 `Function` 构造器创建：

```js
function fn() {}
console.log(fn.__proto__.constructor);   // ƒ Function() { [native code] }

// new Function('debugger')(); 也是"自运行"，同样触发 debugger
new Function("debugger")();
```

**解决方案：改写 `Function` 的原型构造器**（注意：直接改 `Function` 变量没用，因为代码是通过原型链调用构造器的）：

```js
// 先保留一份原始构造器
var qiaofu_function_constructor = (function () {}).__proto__.constructor;

// 改写原型构造器：把函数体里的 "debugger" 干掉
(function () {}).__proto__.constructor = function (arg) {
    if (arg === "debugger") {
        return function () {};          // 无害函数替换
    } else {
        return new qiaofu_function_constructor(arg);
    }
};
```

## 八、window 全局对象

`window` 是浏览器的全局对象。不写任何前缀访问一个标识符，默认就是访问 `window`：

```js
eval === window.eval;            // true
setInterval === window.setInterval;  // true

var a = 10;
a === window.a;                  // true
function fn() {}
fn === window.fn;                // true

window.mm = "爱你";
console.log(mm);                 // "爱你"
```

**通过 window 把闭包内的功能暴露到全局**（很多加密 JS 包的写法）：

```js
(function (w) {
    let tools = {
        b64: function () { return "b64"; },
        md5: function () { return "MD5"; }
    };
    w.jiami = {                     // 挂到全局
        AES: function (msg) {
            return tools.b64(), tools.md5(), "god like";
        },
        RSA: function () {
            console.log("我是RSA");
        }
    };
})(window);

jiami.AES("吃了么");    // 全局调用
```

> **window 是整个浏览器的全局作用域。** 逆向时，常通过给 window 挂属性来定位加密函数入口。

## 九、call 和 apply

`call`/`apply` 可以**指定函数内部 `this` 指向的对象**来调用函数：

```js
function People(name, age) {
    this.name = name;
    this.age = age;
    this.chi = function (w1, w2) {
        console.log(this.name, "在吃", w1, w2);
    };
}
var p1 = new People("alex", 18);

// 普通调用
p1.chi("馒头", "大饼");

// call：函数.call(对象, 参数1, 参数2...)
// 作用：把对象作为 this 传给函数，参数逐个传
function eat(w1, w2) {
    console.log(this.name, "在吃", w1, w2);
}
eat.call(p1, "查克拉", "元宇宙");

// apply：与 call 几乎一样，区别是参数必须放数组里
eat.apply(p1, ["苞米茬子", "大饼子"]);
```

**bind（三兄弟里的老三）**：不立即执行，而是**返回一个绑定好 this 的新函数**：

```js
function eat(w1, w2) {
    console.log(this.name, "在吃", w1, w2);
}
var eatBound = eat.bind(p1);      // 绑定 this 为 p1，返回新函数（不立即执行）
eatBound("馒头", "大饼");          // 之后再调用

// bind 也可以"预传部分参数"（柯里化，逆向偶尔见）
var eatP1 = eat.bind(p1, "馒头");  // 预传第一个参数
eatP1("大饼");                     // 只需再传第二个参数
```

| 方法 | 是否立即执行 | this 指向 | 参数传递方式 |
| ---- | ----------- | --------- | ------------ |
| `call` | 立即 | 第一个参数 | 逐个列出 |
| `apply` | 立即 | 第一个参数 | 数组 |
| `bind` | 不执行（返回新函数） | 第一个参数 | 逐个列出 |

> 逆向只需记住执行逻辑顺序：**call/apply 把第一个参数变成 this，其余参数照常传给函数**。常用于框架设计和"借用方法"。

## 十、ES6 箭头函数

```js
var fn = function () {};     // 等价
var fn = () => {};

var fn = function (name) {}; // 以下三种等价
var fn = name => {};
var fn = (name) => {};

var fn = function (name, age) {};  // 等价
var fn = (name, age) => {};

// 函数体只有一句话时，可以省略 {} 和 return
var add = (a, b) => a + b;
```

> 注意：箭头函数没有自己的 `this`（继承外层），且不能用 `new` 调用。逆向遇到箭头函数要留意它捕获的是外部 this。

## 十一、Promise（滑块验证、异步）

Promise 用来处理异步操作，有三种状态：**pending（进行中）→ fulfilled（成功）/ rejected（失败）**。

```js
function send(url) {
    return new Promise(function (t, f) {   // t: resolve 成功; f: reject 失败
        if (url !== "qqqq") {
            t("成功" + url);
        } else {
            f("失败" + url);
        }
    });
}

send("啊啊啊")
    .then(function (data) {      // 成功时执行
        console.log(data);
        return send("qqqq");     // 可以继续返回 Promise 链式调用
    })
    .then(function (data) {
        console.log(data);
    })
    .catch(function (data) {     // 失败时执行
        console.log(data);
    });
```

执行流程：`.then` 接收成功结果；任一步 reject 后，跳过后续 `.then` 直接进入 `.catch`。

> 滑块验证、请求加密常基于 Promise + 定时器实现，理解状态流转有助于定位触发点。

### Promise 的三种写法对比

```js
// 方式一：then/catch（最常见）
fetch("https://api.example.com/data")
    .then(function (r) { return r.json(); })
    .then(function (data) { console.log(data); })
    .catch(function (err) { console.log(err); });

// 方式二：async/await（现代写法，阅读性最好）
// async 函数里的 await 会"暂停"等待 Promise 完成
async function loadData() {
    try {
        var resp = await fetch("https://api.example.com/data");
        var data = await resp.json();
        console.log(data);
    } catch (err) {
        console.log(err);
    }
}
loadData();

// 方式三：Promise.all（并行等待多个请求）
var p1 = fetch("/a");
var p2 = fetch("/b");
Promise.all([p1, p2]).then(function (resList) {
    console.log("两个都完成了", resList);
});
```

> **async/await 逆向要点**：现代网站加密/取数大量使用 `async function` + `await`。看到 `await xxx()`，说明 `xxx()` 返回的是 Promise，加密函数往往就在这些异步函数里。

### Promise 状态与执行顺序（易错点）

```js
console.log("1");

setTimeout(function () { console.log("2"); }, 0);   // 宏任务，最后执行
Promise.resolve().then(function () { console.log("3"); });  // 微任务

console.log("4");
// 输出顺序：1 → 4 → 3 → 2
```

> 记住：**同步代码先执行 → 微任务（.then）→ 宏任务（setTimeout）**。逆向追踪异步加密逻辑时，这个顺序能帮你判断代码实际执行先后。

## 十四、JS Hook（钩子）

**Hook（钩子）**：在系统函数被调用前，先执行我们的代码，从而拦截、打印、修改。

### 1. Hook eval

```js
var eval_ = eval;                 // 1. 先保存原始 eval
eval = function (s) {
    console.log(s);               // 2. 打印被 eval 执行的代码
    debugger;                     // 3. 断点
    return eval_(s);              // 4. 再调用原始 eval
};

// 防止被检测（伪装回 native code 的样子）
eval.toString = function () {
    return "function eval() { [native code] }";
};
```

### 2. Hook Function（解决无限 debugger）

```js
// 方式一：替换全局 Function
var Function_ = Function;
Function = function () {
    var last_arg = arguments[arguments.length - 1];
    last_arg = last_arg.replaceAll("debugger", "");
    var arr = [];
    for (var i = 0; i < arguments.length - 1; i++) {
        arr.push(arguments[i]);
    }
    arr.push(last_arg);
    return Function_.apply(this, arr);
};

// 方式二：替换 Function.prototype.constructor（更有效，见第七节）
Function.prototype.constructor_ = Function.prototype.constructor;
Function.prototype.constructor = function () {
    var last_arg = arguments[arguments.length - 1];
    last_arg = last_arg.replaceAll("debugger", "");
    var arr = [];
    for (var i = 0; i < arguments.length - 1; i++) {
        arr.push(arguments[i]);
    }
    arr.push(last_arg);
    return Function.prototype.constructor_.apply(this, arr);
};
```

### 3. Hook 属性（例如 cookie）

用 `Object.defineProperty` 拦截 `document.cookie` 的读写：

```js
(function () {
    var v;
    Object.defineProperty(document, "cookie", {
        set: function (val) {
            console.log("有人来存 cookie 了:", val);
            v = val;
            if (val.indexOf("uuid") > -1) { debugger; }
            return val;
        },
        get: function () {
            console.log("有人提取 cookie 了");
            debugger;
            return v;
        }
    });
})();
```

> 逆向中常用的 hook 对象：`eval`、`Function`、`JSON.stringify`、`JSON.parse`、`setInterval`、`setTimeout`、`document.cookie`。

## 十五、localStorage 与 sessionStorage

浏览器本地存储（类似小型非关系型数据库），二者 API 一样，区别：

- `localStorage`：**永久存储**（关闭浏览器还在）；
- `sessionStorage`：**临时存储**（关闭浏览器就没了）。

```js
localStorage.setItem(key, value);    // 存（同 key 覆盖）
localStorage.getItem(key);           // 取
localStorage.removeItem(key);        // 删

sessionStorage.setItem(key, value);
sessionStorage.getItem(key);
```

> **抓数据时要把 localStorage/sessionStorage 清空**——JS 会直接从本地拿到这些值（比如加密密钥、状态标志），不清理就看不到加密过程。
>
> `document.cookie` 也是本地存储，本质是一个有失效时间的大字符串。

## 十六、arguments

所有函数都有 `arguments`，用来接收所有传入的参数（JS 函数允许传入超过形参数量的参数）：

```js
function sad(a) {
    console.log(arguments);        // [Arguments] { '0': 4, '1': 5, '2': 9, '3': 7 }
```

## 十八、正则表达式（RegExp）

JS 逆向中经常看到 `.replace(/xxx/g, ...)`、`.match(/.../)` 这类代码，属于 JS 正则。

### 1. 创建正则

```js
// 字面量写法（推荐）
var re = /abc/;
// 构造函数写法
var re2 = new RegExp("abc");
```

### 2. 修饰符

```js
/abc/g    // g：全局匹配（匹配所有，不写只匹配第一个）
/abc/i    // i：忽略大小写
/abc/m    // m：多行匹配
```

### 3. 常用方法

```js
var s = "ab12cd34ef56";

// test：判断是否匹配，返回布尔
console.log(/12/.test(s));          // true

// match：返回匹配结果
console.log(s.match(/\d+/));        // ['12']
console.log(s.match(/\d+/g));       // ['12', '34', '56']（全局）

// replace：替换（配合正则做清洗）
console.log(s.replace(/\d+/g, "#"));   // ab#cd#ef#
console.log(" 前后空格  ".replace(/\s+/g, ""));  // 前后空格

// exec：正则对象的方法，返回匹配详情
var re = /(\d+)([a-z]+)/;
console.log(re.exec("12ab34cd"));   // ['12ab', '12', 'ab']
```

### 4. 逆向实战：提取和清洗

```js
// 提取 HTML 里的数字
var html = "共 <span class='num'>12345</span> 条记录";
var num = html.match(/\d+/)[0];
console.log(num);   // 12345

// 去掉所有空格和换行（压缩字符串）
var messy = "我 爱\n你";
console.log(messy.replace(/\s+/g, ""));   // 我爱你
```

## 十九、深拷贝与浅拷贝

### 1. 浅拷贝的问题

```js
var a = {name: "alex", hobby: ["打球", "游泳"]};
var b = {...a};        // 浅拷贝：只复制第一层

b.hobby.push("唱歌");  // 修改内层数组
console.log(a.hobby);  // ['打球', '游泳', '唱歌']  —— a 也被改了！
```

原因：浅拷贝时内层对象/数组只是**引用**（指向同一个地址），没有真正复制。

### 2. 深拷贝

```js
// 方法一：JSON 序列化（简单，但会丢失函数/undefined）
var deep = JSON.parse(JSON.stringify(a));

// 方法二：递归手写（了解）
function deepClone(obj) {
    if (obj === null || typeof obj !== "object") return obj;
    var res = Array.isArray(obj) ? [] : {};
    for (var k in obj) {
        res[k] = deepClone(obj[k]);
    }
    return res;
}
var deep2 = deepClone(a);
```

> 逆向中加密函数常会**复制一份对象/数组再处理**，如果发现"改了一个变量另一个也变"，往往是浅拷贝（引用传递），这是排查逻辑的重要线索。

### 2. Set（不重复的集合）


## 二十一、jQuery 基础（write less, do more）

jQuery 是一个曾经非常流行的 JS 库，把繁琐的 DOM 操作和事件绑定简化。虽然现在新项目用得少，但**老网站/逆向场景大量存在**，必须能看懂。

> jQuery 三大版本 1.x / 2.x / 3.x，很多公司选用兼容性最好的 1.x（如 1.9.1）。它本质就是一个 JS 文件，用 `<script src="jquery.min.js">` 引入即可。

### 1. `$` 是什么

在 jQuery 中，`$` 就是 jQuery 的别名，`$()` 可以把一个 DOM 元素（或选择器）转成 jQuery 对象，从而调用 jQuery 方法：

```js

$(".class")      // 按 class
$("input[type='submit']")   // 按属性
```

### 2. 事件绑定

```js

    document.querySelector(".btn").onclick = function () {
        document.querySelector(".mydiv").innerText = "我好怕怕啊";
    };

// jQuery：页面加载完成后绑定
$(function () {                    // 等价于 $(document).ready(function(){})
    $(".btn").click(function () {  // 给 class=btn 的元素绑定点击
        $(".mydiv").text("我要上天");  // 修改文本

```

### 3. 属性/取值常用方法（重点：有参=赋值，无参=取值）

## 二十二、Ajax 请求（核心）

**Ajax** 让页面不刷新就能向后端要数据。逆向抓包时，网页里的数据基本都来自 Ajax 请求。

### 1. 原生 XMLHttpRequest（底层）

```js
// 1. 创建请求对象
var xhr = new XMLHttpRequest();

// 2. 配置：方法、URL、是否异步（true 异步）
xhr.open("GET", "https://api.example.com/data", true);

// 3.（可选）设置请求头，POST 时常用
// xhr.setRequestHeader("Content-Type", "application/json");

// 4. 监听状态变化（readyState: 4=全部完成）
xhr.onreadystatechange = function () {
    if (xhr.readyState === 4) {
        if (xhr.status >= 200 && xhr.status < 300) {
            console.log(xhr.responseText);      // 响应文本（常是 JSON 字符串）
            var data = JSON.parse(xhr.responseText);
        } else {
            console.error("请求失败", xhr.status);
        }
    }
};

// 5. 发送（GET 传 null；POST 可传 JSON.stringify(data)）
xhr.send(null);
```

> **readyState**：0 未初始化 / 1 已 open / 2 已 send / 3 部分响应 / 4 全部完成。
>
> 逆向提示：`XMLHttpRequest.prototype.open` 常被 Hook 用来给请求参数加密，Hook 它就能看到加密入口。

POST 版本：

```js
var xhr = new XMLHttpRequest();
xhr.open("POST", "https://api.example.com/submit", true);
xhr.setRequestHeader("Content-Type", "application/json");
xhr.onreadystatechange = function () {
    if (xhr.readyState === 4 && xhr.status === 200) {
        console.log(xhr.responseText);
    }
};
xhr.send(JSON.stringify({username: "test", password: "123456"}));
```

### 2. jQuery 的 $.ajax

```js
$.ajax({
    url: "/ajax_post",            // 请求地址
    method: "post",               // 或 type: "get"
    headers: {                    // 自定义请求头
        "Content-Type": "application/json;charset=utf-8"
    },
    data: JSON.stringify({name: "alex", id: "10086"}),  // 请求体
    dataType: "json",             // 期望返回的数据类型
    beforeSend: function (req) {  // 发送前钩子（常在这里加签名/加密）
        req.setRequestHeader("token", "i-can-do-it");
    },
    success: function (back) {    // 成功回调
        console.log(back);
    },
    error: function (xhr, status, error) {   // 失败回调
        console.error(status, error);
    },
    complete: function (xhr, status) {       // 无论成败都会执行
        console.log("完成", status);
    }
});
```

> **逆向重点**：`beforeSend` 里给请求加 `token`/`sign` 参数、`headers` 里放加密头，都是加密逻辑的藏身之处。

### 3. axios（现代框架，基于 Promise）

```js
axios.post("/movies", {page: 10086}, {
    headers: {"xxxx": "xxxx"}     // 请求头
}).then(function (resp) {
    console.log(resp.data);       // axios 自动把响应解析为 JSON
});
```

> axios 默认收发 JSON（request payload 直接是 JSON），比 jQuery 简单，逆向时在浏览器 Network 里看到的就是 `Request Payload`。

## 二十三、axios 拦截器（全局加解密）

网站会对**每一次请求**统一加密、对**每一次响应**统一解密。如果靠手写，每个请求都要写一遍，太麻烦——axios 用**拦截器**统一处理：

```js
// 请求拦截器：每次请求发出前执行（可在这里统一加密参数/加签名）
axios.interceptors.request.use(function (config) {
    console.log("请求拦截器：可以对数据进行加密", config);
    // 例如：config.headers['sign'] = md5(config.data)
    return config;                // 必须返回 config，否则请求中断
}, function (error) {
    return Promise.reject(error);
});

// 响应拦截器：每次响应回来后执行（可在这里统一解密）
axios.interceptors.response.use(function (response) {
    console.log("响应拦截器：可以对数据进行解密");
    return response.data;         // 直接返回 data，业务层拿到即数据
}, function (error) {
    return Promise.reject(error);
});

// 业务层代码就非常干净了
window.onload = function () {
    axios.post("/movies", {page: 10086}).then(function (data) {
        console.log(data);        // 加解密都被拦截器处理好了
    });
};
```

> **逆向突破口**：看到 `interceptors.request.use` / `interceptors.response.use`，说明网站有**全局加密/解密逻辑**。只要定位到拦截器回调里的 `config` 处理代码，就能找到加密函数。

## 二十四、JSONP（跨域方案，老网站常见）

**问题**：浏览器同源策略限制跨域请求。

**JSONP 思路**：`<script>` 标签不受同源限制。请求时带一个 `callback` 参数，服务器返回 `callback(json数据)` 形式的 JS 代码，浏览器自动执行。

抓包看到返回形如 `jQuery36002530792718956838_xxx({...})` 的就是 JSONP。

### 前端写法

```js
$.ajax({
    url: "/process_jsonp",
    method: "get",
    dataType: "jsonp",   // 关键：声明是 jsonp
    jsonp: "cb",         // 传给服务器的回调参数名（服务器按此接收）
    success: function (data) {   // 直接拿到数据
        console.log(data);
    }
});
```

### Python 模拟服务器（理解原理）

```python
from flask import Flask, request, json
app = Flask(__name__)

@app.route("/process_jsonp", methods=["GET"])
def process_jsonp():
    cb = request.args.get("cb")          # 拿到回调函数名
    data = {"name": "alex", "age": 18}
    return cb + "(" + json.dumps(data) + ")"   # 用回调名包裹数据返回
```

### Python 爬虫处理 JSONP

```python
import requests, re, json

url = "http://127.0.0.1:5000/process_jsonp"
params = {"cb": "haha", "_": "1654767783595"}   # 固定 callback，_ 是防缓存
resp = requests.get(url, params=params)
print(resp.text)   # haha({"name": "alex", "age": 18})

# 用正则提取括号里的 JSON
m = re.search(r"\((.*)\)", resp.text, re.S)
data = json.loads(m.group(1))
print(data)   # {'name': 'alex', 'age': 18}
```

## 二十五、小结

- **变量提升**：`var` 声明提升到顶部，推荐用 `let`/`const`；
- **闭包**：私有变量 + 返回接口，是加密 JS 包的常见写法；
- **原型链**：方法查找路径，可用来 Hook 构造器反无限 debugger；
- **window**：全局对象，加密函数常挂载到 window 暴露入口；
- **eval / Function / Promise / 定时器**：反爬混淆与异步的关键点；
- **正则 / 深拷贝 / Map / Set**：逆向提取、复制数据、去重映射的高频工具；
- **Hook**：拦截系统函数/属性，是 JS 逆向定位加密逻辑的核心手段；
- **jQuery / Ajax / axios / JSONP**：网页数据请求的四种方式，`beforeSend`、axios 拦截器里往往藏着全局加解密逻辑。
