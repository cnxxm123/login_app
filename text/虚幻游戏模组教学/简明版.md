# 虚幻引擎 Mod 安装简明指南

> 快速上手版。完整版见同目录《虚幻引擎Mod安装指南.md》。
>
> **先记一条总规则：游戏与 Mod 下载页的安装说明优先。** `~mods`、`LogicMods`、Pak 文件名 `_P`、UE4SS 的目录结构和代理 DLL 名称都可能只适用于某个游戏、某个 Mod 或某个发布包，不能跨游戏照搬。

---

## 一、先判断：这个 Mod 要求什么？

| Mod 页面/README 明确写的是 | 常见路线 | 你应该做什么 |
|---|---|---|
| Steam 创意工坊、mod.io、官方 SDK | 官方 Mod 支持 | 按游戏平台或官方说明安装，不额外注入加载器。 |
| Requires UE4SS、Lua Mod、C++ Mod | UE4SS | 按 Mod 要求安装对应版本 UE4SS，并把 Mod 放入当前 UE4SS 的实际 `Mods/` 目录。 |
| `Paks/~mods`、`LogicMods` 或其他指定目录 | 资源 / 蓝图 Mod | 仅按该 Mod 明确指定的路径和完整文件结构安装。 |
| 未写清楚 | 不确定 | 不要猜路径；先看压缩包 README、发布页评论或游戏社区置顶说明。 |

> UE 游戏可能使用 `.pak`，也可能还需要 `.sig`、`.utoc`、`.ucas` 等配套文件。不要只抽取一个 `.pak` 文件。

---

## 二、Pak / 资源 Mod：只在作者明确指定时使用

例如 Mod 页面明确写“放到 `游戏名/Content/Paks/~mods/`”时：

```text
游戏目录/游戏名/Content/Paks/
├── 原版资源文件               ← 不要修改
└── ~mods/                    ← 仅当作者明确要求时创建
    ├── 作者提供的 Mod 文件组
    └── 可能的 .pak/.sig/.utoc/.ucas 配套文件
```

注意：

- `~mods` 不是所有 UE 游戏的通用目录。
- `_P` 不等于所有游戏都保证的“最高优先级”；不要自行重命名。
- 游戏更新后 Mod 可能失效，也不能保证某个目录一定不受更新影响。
- 若作者写 `LogicMods`、专用加载器或官方 Mod 目录，按作者写的做，不要改放到 `~mods`。

## 三、UE4SS 脚本 Mod（Lua / C++）

### 1. 安装 UE4SS

1. 从 [RE-UE4SS Releases](https://github.com/UE4SS-RE/RE-UE4SS/releases) 下载 Mod/游戏说明要求的标准包；普通玩家通常选 `UE4SS_vX.X.X.zip`，不是 `zDEV` 开发包。
2. 关闭游戏，找到**真实游戏 EXE**所在目录。很多游戏位于：
   ```text
   游戏根目录/游戏名/Binaries/Win64/
   ```
   但应以实际运行的 `*-Win64-Shipping.exe` 或游戏社区说明为准。
3. 按当前 UE4SS 发布包说明，把包内文件完整解压到真实 EXE 所在目录。
4. 在解压结果中找到 `UE4SS.dll`、`UE4SS-settings.ini`、`Mods/` 与 `Mods/mods.txt`。**不要根据版本号猜测是否存在 `ue4ss/` 子目录。**

### 2. 安装 Lua / C++ Mod

保留作者提供的目录结构，并放进当前 UE4SS 实际的 `Mods/` 目录。常见形式：

```text
<当前 UE4SS 工作目录>/Mods/
├── FastHatch/
│   └── scripts/main.lua       ← Lua Mod 示例
└── SomeCppMod/
    └── dlls/main.dll          ← C++ Mod 示例
```

然后编辑同一位置的 `Mods/mods.txt`，按 Mod 作者要求启用：

```text
FastHatch : 1
SomeCppMod : 1
Keybinds : 1                   ← 若当前包带有它，保持在最后
```

> 蓝图/资源 Mod 是否需要 `BPModLoaderMod`、`LogicMods` 或其他目录，不是通用规则，以该 Mod 说明为准。

### 3. 验证是否成功

- 基础安装**不一定会弹 GUI 或控制台窗口**。
- 查找 `UE4SS.log`，确认时间戳更新、没有明显错误，并搜索 Mod 名称。
- 按 Mod 说明的热键或游戏内功能验证。
- 需要 GUI 时，再按当前版本设置文件与发布说明启用。

## 四、常见报错速查

| 现象 | 建议处理 |
|---|---|
| 缺少 `VCRUNTIME140.dll` / `MSVCP140.dll` | 从微软官方安装 Visual C++ Redistributable 2015–2022，对应游戏位数。 |
| UE4SS 日志都没有生成 | 确认文件在真实游戏 EXE 目录；检查代理 DLL 是否被防护软件隔离；核对加载器和游戏版本。 |
| 启动崩溃 | 先移走全部 Mod，仅验证 UE4SS；查看日志。只有当前版本/社区明确建议时，再尝试 `bUseUObjectArrayCache = false`。 |
| GUI 白屏/花屏 | 确认 GUI 已启用；若当前 UE4SS 版本发布说明建议，可尝试 `GraphicsAPI = dx11`。 |
| Mod 无效果 | 核对 Mod 要求、完整文件结构、实际 `Mods/` 与 `mods.txt`、前置 Mod，以及 `UE4SS.log`。 |
| 联机/反作弊游戏 | 不要在反作弊、公共服务器、竞技或未明确允许的联机环境使用注入/脚本 Mod。 |

## 五、备份与迁移

只备份自己拥有游戏中的 Mod、配置、存档和日志：

- 记录 UE4SS 版本和每个 Mod 的来源链接。
- 备份实际 `Mods/`、`mods.txt`、设置文件、资源 Mod 完整文件组与存档。
- 不要打包、传播或指导绕过平台验证的游戏本体；游戏平台的移动、修复和授权通过其官方客户端处理。

---

## 六、核心口诀

> **先看游戏和 Mod 页面 → 再确认加载器与真实目录 → 完整保留作者文件结构 → 用日志验证，不靠猜路径。**
