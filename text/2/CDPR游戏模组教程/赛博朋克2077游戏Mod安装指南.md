# CDPR 游戏 Mod 安装指南（REDengine 4 篇）

> 本指南主要覆盖 **《赛博朋克 2077》** 和 **《巫师 3：狂猎》次世代版**，它们都跑在 **REDengine 4** 上，Mod 工具链共享大半。
>
> 《巫师 3》老版（Pre-Next-Gen）跑的是 REDengine 3.x，Mod 生态围绕 **ModKitchen / Script Merger / QuickBMS** 展开，和本文重点区别较大，本文最后一节简要说明。
>
> **总规则**：**游戏版本 + Mod 工具（Red4Ext / CET / redscript）版本 + Mod 本身版本三者必须匹配**。CDPR 每次大更新都会打乱工具兼容性；玩老档时最好锁定不自动更新。

---

## 一、REDengine 4 的 Mod 生态概览

REDengine 4 是 CDPR 自研引擎。CDPR 一开始对 Mod 态度冷淡，2077 早期完全靠社区逆向；到 2022 年发布 **REDmod 官方工具**（1.6 更新）算是正式承认了 Mod 存在，但**真正的深度 Mod 生态仍然主要建立在社区框架上**。

### 主要工具与它们的分工

| 工具 | 提供方 | 干什么 |
|---|---|---|
| **REDmod** | CDPR 官方 | 打包/加载 `.archive` 资源、脚本、动画、音效、TweakDB；官方支持的 Mod 格式 |
| **Red4Ext** | 社区 | C++ 原生插件框架，注入游戏进程；很多其他工具的底座 |
| **Cyber Engine Tweaks（CET）** | 社区 | 游戏内 ImGui 控制台 + Lua Mod API + Overlay UI |
| **redscript** | 社区 | RED4 脚本语言的社区编译器，让 Mod 能改写游戏原生脚本 |
| **ArchiveXL** | 社区 | 增强 `.archive` 资源加载能力（无冲突动态加载、多变体、外观扩展） |
| **TweakXL** | 社区 | 用 YAML 增删改 TweakDB（游戏内几乎所有数值/属性都在这里） |
| **Codeware** | 社区 | 给 redscript 补充更多游戏底层 API |
| **Input Loader** | 社区 | 让 Mod 自定义按键绑定 |
| **REDkit** | CDPR 官方 | 巫师 3 次世代版的官方开发工具集（2024 发布） |

**它们的层级关系**：

```text
游戏进程 (Cyberpunk2077.exe)
     │
     │  ① Windows DLL 搜索顺序
     ▼
Red4Ext 代理 DLL（.asi），位于 bin/x64/plugins/
     │
     │  ② Red4Ext 扫描 bin/x64/plugins/ 里的原生插件
     ▼
Cyber Engine Tweaks（CET）    ← 是一个 Red4Ext 插件
redscript                     ← 是一个 Red4Ext 插件，负责编译 r6/scripts/
ArchiveXL                     ← 是一个 Red4Ext 插件，负责扩展 .archive 加载
TweakXL                       ← 是一个 Red4Ext 插件，负责 TweakDB 覆盖
     │
     ▼
Lua Mod（CET）、redscript Mod、YAML Mod（TweakXL）、archive Mod
```

**看清楚：CET / redscript / ArchiveXL / TweakXL 都是 Red4Ext 之上的插件**——所以 Red4Ext 是绝大多数 Mod 的通用前置。

REDmod 是并列的另一条链，走 CDPR 官方加载路径，需要用带 `--launcher-skip` + `--modded` 的启动参数。

## 二、原理：REDengine 4 是怎么加载 Mod 的

### 2.1 Red4Ext：DLL 代理注入 + RTTI 挂钩

- **Windows DLL 搜索顺序**：加载 `Cyberpunk2077.exe` 时会先在 EXE 目录查依赖 DLL。游戏本来就加载 `winmm.dll`（Windows 多媒体 API）；Red4Ext 把自己伪装成 `winmm.dll` 放到游戏的 `bin/x64/` 目录，就会被系统优先加载。
- 加载后 Red4Ext 挂钩到游戏引擎的 **RTTI（Run-Time Type Information）系统**——REDengine 内部所有类、方法、属性都注册在 RTTI 里，Red4Ext 通过它拿到游戏内部的每一个可调用符号，暴露给 C++ / redscript / Lua 使用。
- Red4Ext 再扫 `red4ext/plugins/` 加载所有 `.dll` 插件（CET、redscript 等）。

### 2.2 archive 资源加载

REDengine 4 用 `.archive` 归档存所有游戏资源（贴图、模型、声音、动画、TweakDB、redscript）。默认加载顺序：

1. `archive/pc/content/`（游戏本体资源，不要动）
2. `archive/pc/ep1/`（幻影自由 DLC）
3. `archive/pc/mod/`（**社区 Mod 手动放这里**）
4. `mods/<modname>/archives/pc/mod/`（REDmod 模式，通过官方 launcher 加载）

**后加载覆盖先加载**——放在 `mod/` 目录的 archive 覆盖官方同路径资源。**ArchiveXL** 在此之上又加了一层：允许 Mod 声明「我要往这个已有列表里加一条」而不是完全替换，解决了多 Mod 争夺同一个 archive 时的冲突。

### 2.3 redscript：脚本合并

游戏的 gameplay 逻辑用 REDscript 写，编译成 `.script` 字节码打包在 archive 里。**redscript 编译器**允许 Mod 用 `@replaceMethod` / `@wrapMethod` / `@addMethod` 注解**在源码层面**修改游戏原生类。

- Mod 作者写 `.reds` 源码放到 `r6/scripts/<modname>/`。
- 游戏启动时 redscript 编译器把所有 Mod 源码和 CDPR 原生源码一起编译成新的 `final.redscripts`，覆盖游戏原有的字节码。
- 多个 Mod 用 `@wrapMethod` 时可以合并（一层一层套），`@replaceMethod` 是硬替换（第二个 Mod 用同名 replace 就冲突）。

### 2.4 TweakXL：TweakDB 数据覆盖

游戏内几乎所有数值（枪械伤害、经验曲线、物品价格、Perk 效果）都放在 **TweakDB**——一个巨大的键值数据库。TweakXL 让 Mod 用 YAML 声明「把 `Items.Ajax.damage` 从 500 改为 800」，运行时合并进 TweakDB。多个 Mod 改同一个键时按加载顺序覆盖。

- Mod YAML 放到 `r6/tweaks/<modname>/`。

## 三、必装前置

装几乎任何 2077 Mod 都要有这几层：

| 前置 | 什么时候需要 | 下载 |
|---|---|---|
| **Red4Ext** | 装任何 C++ 插件 Mod（CET/redscript/ArchiveXL/TweakXL 都需要） | [Nexus](https://www.nexusmods.com/cyberpunk2077/mods/2380) / [GitHub](https://github.com/WopsS/RED4ext) |
| **Cyber Engine Tweaks（CET）** | Mod 页面写「Requires CET」、Lua Mod | [Nexus](https://www.nexusmods.com/cyberpunk2077/mods/107) / [GitHub](https://github.com/maximegmd/CyberEngineTweaks) |
| **redscript** | Mod 写「Requires redscript」、修改游戏 gameplay 脚本 | [GitHub](https://github.com/jac3km4/redscript) |
| **ArchiveXL** | 装带 `.xl` 文件的 archive Mod、外观 Mod | [Nexus](https://www.nexusmods.com/cyberpunk2077/mods/4198) |
| **TweakXL** | 装带 `.yaml` 数值调整 Mod | [Nexus](https://www.nexusmods.com/cyberpunk2077/mods/4197) |
| **Codeware** | 部分 redscript Mod 需要 | [GitHub](https://github.com/psiberx/cp2077-codeware) |
| **Input Loader** | 需要自定义按键的 Mod | [Nexus](https://www.nexusmods.com/cyberpunk2077/mods/4575) |

一般玩家最常见的组合是 **Red4Ext + CET + redscript + ArchiveXL + TweakXL** 五件套，装完了绝大多数 Mod 都能跑。

**版本严格匹配当前游戏版本**——每次 CDPR 更新，这些工具都要重新出适配版。Nexus 页面会写「For 2.13」「For 2.20」，请对号入座。

## 四、安装步骤

### 4.1 通用准备

1. **备份存档**：`%USERPROFILE%\Saved Games\CD Projekt Red\Cyberpunk 2077\`。
2. **锁定游戏更新**（推荐）：Steam → 游戏属性 → 更新 → 「仅在启动时更新」，或用 depot downloader 把游戏锁在你要 Mod 的版本上。
3. 记下当前游戏版本号（主菜单右下角）。
4. **不要把游戏装在 `C:\Program Files\`**，避免 UAC 问题。

### 4.2 装 Red4Ext

1. 从 Nexus/GitHub 下载对应游戏版本的 Red4Ext。
2. 解压后压缩包里通常有：
   ```text
   bin/
   └── x64/
       ├── winmm.dll             ← Red4Ext 的代理 DLL
       └── plugins/              ← Red4Ext 插件目录
           └── ...（Red4Ext 自己的运行时文件）
   red4ext/
   ├── LICENSE.txt
   └── plugins/                  ← 有些版本也在这个位置
   ```
3. 把压缩包**整体覆盖**到游戏根目录（Cyberpunk2077.exe 的**上级**，即 `Cyberpunk 2077/`）。
4. 启动游戏一次，进主菜单再退出。
5. 打开 `red4ext/logs/`（或 `Cyberpunk 2077/red4ext/logs/`），看有没有生成日志、内容有没有报错。

### 4.3 装 CET

1. 从 Nexus 下载对应版本 CET。
2. 解压后压缩包里通常是：
   ```text
   bin/
   └── x64/
       └── plugins/
           └── cyber_engine_tweaks/
               ├── mods/            ← Lua Mod 放这里
               ├── scripts/
               └── ...其他运行时文件
   ```
3. **整体覆盖**到游戏根目录。
4. 启动游戏，第一次会弹 CET Overlay 窗口要求你输入 Overlay 快捷键（默认没绑定，通常设为 `~` 或 `Home`）。
5. 进游戏按 Overlay 快捷键，出现 CET 控制台就装好了。

### 4.4 装 redscript

1. 下载 redscript CLI 与其配套包（Nexus 上的 redscript Mod 页面）。
2. 解压后覆盖到游戏根目录。它会往 `engine/`、`r6/scripts/`、`r6/config/`、`red4ext/plugins/redscript/` 里放文件。
3. 启动游戏。redscript 每次启动都会重新编译所有 `.reds`，生成 `r6/cache/final.redscripts`。
4. 编译失败会弹一个红色的报错窗，同时把日志写到 `r6/logs/redscript_rCURRENT.log`。

### 4.5 装 ArchiveXL / TweakXL

两者都是 Red4Ext 插件，装法一致：

1. 下载对应版本 ArchiveXL 和 TweakXL。
2. 解压后压缩包里是 `red4ext/plugins/ArchiveXL/` 或 `red4ext/plugins/TweakXL/` 结构。
3. 整体覆盖到游戏根目录。

### 4.6 装第一个内容 Mod

以「Appearance Change Unlocker」这类简单 CET Mod 为例：

1. 从 Nexus 下载。
2. 解压看结构；如果是 CET Lua Mod，压缩包里是：
   ```text
   bin/x64/plugins/cyber_engine_tweaks/mods/AppearanceChangeUnlocker/
   ├── init.lua
   └── ...
   ```
3. 整体覆盖到游戏根目录（保留完整路径层级）。
4. 进游戏，打开 CET Overlay → 顶部菜单会多出对应 Mod 的界面。

再举一个 redscript + TweakXL 混合 Mod 的例子——Mod 压缩包结构可能是：

```text
r6/
├── scripts/BetterCraftBench/
│   └── main.reds                    ← redscript 源码
└── tweaks/BetterCraftBench/
    └── prices.yaml                  ← TweakXL 数值改动
archive/pc/mod/
└── BetterCraftBench.archive         ← 资源包（如有）
```

直接把 `r6/` 和 `archive/` 整体覆盖到游戏根目录。

### 4.7 用 REDmod（官方方式）

REDmod 是 CDPR 官方 Mod 系统，主要处理**资源打包**和**通过官方加载器加载 Mod**。适合作者发布正式 Mod 包，玩家侧不太常单独用。

1. 通过 CDPR REDlauncher 启用 REDmod（自动下载）。
2. REDmod Mod 放在 `mods/<modname>/`，目录里有 `info.json` 元数据和资源。
3. 用 REDlauncher 的「Play with mods」选项启动，或加 `-modded` 参数。

**REDmod 和 Red4Ext 生态可以共存**，二者互不冲突：REDmod 走 CDPR 官方加载路径，Red4Ext 走 DLL 代理。

## 五、目录结构总览

装了完整 Mod 环境后，游戏目录大致长这样：

```text
Cyberpunk 2077/
├── bin/x64/
│   ├── Cyberpunk2077.exe
│   ├── winmm.dll                    ← Red4Ext 代理 DLL
│   └── plugins/                     ← Red4Ext 插件目录
│       └── cyber_engine_tweaks/
│           ├── mods/                ← CET Lua Mod 放这里
│           │   ├── AppearanceChangeUnlocker/
│           │   └── NativeSettings/
│           └── scripts/
├── red4ext/
│   ├── plugins/
│   │   ├── redscript/               ← redscript 编译器
│   │   ├── ArchiveXL/               ← ArchiveXL 插件
│   │   ├── TweakXL/                 ← TweakXL 插件
│   │   └── Codeware/                ← Codeware 插件
│   └── logs/                        ← Red4Ext 日志
├── r6/
│   ├── scripts/                     ← redscript 源码，每个 Mod 一个子目录
│   │   ├── BetterCraftBench/
│   │   └── MyOtherMod/
│   ├── tweaks/                      ← TweakXL YAML 数值 Mod
│   │   └── BetterCraftBench/
│   ├── cache/
│   │   └── final.redscripts         ← redscript 编译结果
│   ├── config/                      ← Mod 配置
│   └── logs/                        ← 编译日志、Mod 日志
├── archive/pc/
│   ├── content/                     ← 游戏原版资源（不要动）
│   ├── ep1/                         ← 幻影自由 DLC
│   └── mod/                         ← 资源 Mod 放这里
│       ├── SomeModArchive.archive
│       └── SomeModArchive.xl        ← 配 ArchiveXL 的可选清单
├── mods/                            ← REDmod 官方 Mod
│   └── <modname>/
│       └── info.json
├── engine/                          ← 引擎运行时
└── ...
```

**关键约定**：

- **CET Lua Mod**：一律放 `bin/x64/plugins/cyber_engine_tweaks/mods/<modname>/`。
- **Red4Ext 原生插件**：`red4ext/plugins/<modname>/`。
- **redscript**：`r6/scripts/<modname>/` 或直接 `r6/scripts/<name>.reds`。
- **TweakXL YAML**：`r6/tweaks/<modname>/`。
- **archive 资源**：`archive/pc/mod/<name>.archive`（配套 `.xl` 一起放）。
- **REDmod**：`mods/<modname>/`（要用官方 launcher 才生效）。

## 六、Mod 管理器：Vortex + REDmod Ext

对 2077 而言，**手动装 Mod 完全可行**——目录结构清晰，Mod 压缩包基本都能直接覆盖到游戏目录。装的 Mod 数量少（< 20 个）不需要管理器。

装大量 Mod 时可以考虑：

- **[Vortex](https://www.nexusmods.com/site/mods/1)**：Nexus 官方，对 2077 有专门的部署插件；一键下载、自动放到正确位置、可禁用/启用。
- **[Cyberpunk 2077 Mod Manager](https://www.nexusmods.com/cyberpunk2077/mods/1859)**（社区）：轻量替代品。

**手动装的排错优势**：文件真实存在，日志能对上；管理器的虚拟文件系统有时候会让路径判断失灵。

## 七、常见问题排查

### Q1：进游戏黑屏 / 主菜单转圈不动

- **90% 是版本不匹配**：确认 Red4Ext、CET、redscript 都是当前游戏版本对应的。CDPR 每次大更新（比如从 2.12 → 2.13）都会打乱兼容性。
- 打开 `red4ext/logs/red4ext.log`，最后几行会有报错。
- 打开 `r6/logs/redscript_rCURRENT.log`，看有没有编译失败——**一个 Mod 的 redscript 编译失败会导致所有 gameplay 脚本编译失败，游戏进不去**。

### Q2：CET 控制台不出来

- 确认 CET 装在正确位置（`bin/x64/plugins/cyber_engine_tweaks/`）。
- 首次运行需要设置 Overlay 快捷键，会有一个 `Overlay disabled - press ~` 的启动提示。
- 快捷键在 `bin/x64/plugins/cyber_engine_tweaks/config.json` 里手动改（键名要用 CET 支持的名称，如 `Home`、`F1`）。

### Q3：装了 archive Mod，游戏里没看到东西

- 确认 `.archive` 放在 `archive/pc/mod/`，不是 `archive/pc/content/`（不要往 content 里丢）。
- 如果 Mod 页面写「Requires ArchiveXL」和「Requires TweakXL」，前置装了吗？
- 装了 ArchiveXL 但 `.xl` 文件没跟着放：archive 里的资源可能加载了但没被游戏引用，等于没生效。
- 外观 Mod 通常还需要 **EquipmentEX / VirtualAtelier / Wardrobe** 之类的中间层 Mod 提供 UI 入口。

### Q4：redscript 编译失败

打开 `r6/logs/redscript_rCURRENT.log` 看具体错误：

- `Method ... not found`：Mod 引用了游戏里不存在的方法——通常是游戏更新后方法名变了，Mod 还没适配。
- `Duplicate method definition`：两个 Mod 都用 `@replaceMethod` 改了同一个方法——只能选一个用，或者装作者提供的兼容 patch。
- 大部分情况：**移出出错的 Mod，等作者更新**。

### Q5：装了 Mod 之后 FPS 大幅下降

- Ultra 4K 贴图 + ArchiveXL 大量外观 Mod 会显著吃显存。
- CET 界面本身开销很小，但个别 Lua Mod 在每帧循环里做重活会拖 FPS。
- 用 Nvidia Overlay 或 CET 自带的 Perf Monitor 定位是哪个 Mod。

### Q6：Steam 自动更新后 Mod 全部失效

- 装 SteamCMD 拉旧版：`steamcmd +login <user> +download_depot 1091500 1091501 <manifest_id>`。
- 或直接把 Mod 全部禁用等社区跟进——通常大更新后 1-2 周内 Red4Ext / CET / redscript 都会发新版。

## 八、卸载

### 单个 Mod

按类型删除对应位置的文件：CET Mod 删 `bin/x64/plugins/cyber_engine_tweaks/mods/<modname>/`，redscript 删 `r6/scripts/<modname>/`，archive 删 `archive/pc/mod/<name>.archive` 和同名 `.xl`。

### 完全卸载 Red4Ext 生态

删除：

- `bin/x64/winmm.dll`
- `bin/x64/plugins/`（Red4Ext 及所有插件）
- `red4ext/`
- `r6/scripts/`、`r6/tweaks/`、`r6/cache/final.redscripts`
- `archive/pc/mod/` 里所有非官方文件

**用 Steam「验证游戏文件完整性」**能把误删的原版文件补回来。

### 存档兼容性

- 只装了 archive / TweakXL / redscript 等**只在启动时生效**的 Mod：卸载后存档通常能干净地读回。
- 装了 CET Lua Mod 或改了游戏状态的 Mod：可能在存档里留下垃圾数据，个别情况下会导致读档异常。深度 Mod 建议开新档卸载。

## 九、安全边界

- **不要用 Mod 进 online 联机内容**——2077 目前是纯单机，未来如果有多人模式，Mod 一定不能带过去。
- **只从 Nexus、GitHub 官方仓库、CDPR 官方 REDlauncher** 下载 Mod。CET/Red4Ext 是可执行 DLL，来源不明的直接不装。
- 版本更新期间**先移出所有 Mod 再启动游戏**，避免脚本崩溃污染存档。
- 备份 `Saved Games\CD Projekt Red\Cyberpunk 2077\` 存档目录。
- 巫师 3 老版走完全不同的 ModKitchen 生态，不要把 2077 的工具塞进去；下面第十节单独说。

## 十、《巫师 3》两个版本的区别

《巫师 3：狂猎》有两条完全独立的 Mod 生态：

### 老版（Steam 「Version 1.32 (Classic)」 / GOG 老包）

- 引擎：REDengine 3.x。
- 目录约定：`Mods/<modname>/content/` + 用 `Script Merger` 合并冲突脚本。
- 主要工具：**Script Merger**（脚本合并）、**Mod Kitchen / QuickBMS**（解包工具）、**Nexus Mod Manager / Vortex**。
- 生态成熟稳定，Mod 数量最大的版本。

### 次世代版（Version 4.x）

- 引擎：REDengine 4，和 2077 同代。
- 官方支持：**REDkit**（2024 年发布，正式 SDK，作者用它开发 Mod）。
- 玩家安装 Mod 时结构与 2077 相似（`bin/x64/plugins/`、`Mods/`）。
- Mod 数量还在追赶老版；许多老 Mod 需要作者重制才能用到次世代版。

**在 Steam 上可以随时在两版之间切换**（游戏属性 → Beta 里有 Classic 分支）。装 Mod 前先想清楚要哪版，工具完全不通用。

---

## 十一、流程总结

```text
① 确认游戏版本、锁定不自动更新
       ↓
② 装 Red4Ext（DLL 代理层，几乎所有 Mod 的前置）
       ↓
③ 装 CET / redscript / ArchiveXL / TweakXL 四件套
       ↓
④ 启动游戏一次，看 red4ext/logs 和 r6/logs 有没有错
       ↓
⑤ 按 Mod 说明装内容 Mod，保留作者提供的目录结构
       ↓
⑥ 进游戏验证；出错先看日志、退出全部 Mod 排查
       ↓
⑦ 游戏大更新前先禁用/移出所有 Mod
```

> 核心口诀：**版本严格匹配 → 前置装齐 → 保留作者目录结构 → 日志先于猜测 → 更新前先禁用。**
