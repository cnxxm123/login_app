# 游戏存档与图形配置文件位置指南（含破解版）

> 整理各游戏引擎的存档和画面配置文件位置，适合制作整合包、迁移存档时参考。

---

## 一、存档位置

### Unity 引擎
| 版本 | 路径 |
|------|------|
| 正版 | `%USERPROFILE%\AppData\LocalLow\<公司名>\<游戏名>\` |
| 破解版 | 同上；部分破解改存**游戏根目录**（便携化处理） |

示例：`AppData\LocalLow\Hinterland\TheLongDark\`

### 虚幻引擎
| 版本 | 路径 |
|------|------|
| 正版 | `%LOCALAPPDATA%\<游戏名>\Saved\SaveGames\` |
| 破解版 | 同上；少数改存游戏根目录 `Save\` |

示例：`AppData\Local\Pal\Saved\SaveGames\`

### RE Engine（卡普空：生化危机/鬼泣/街霸/怪物猎人崛起）
| 版本 | 路径 |
|------|------|
| 正版 | Steam 远程存档或 `steam_settings\` |
| 破解版 | 游戏根目录下，常见文件夹：`steam_settings\`、`save\`、`Profile\` |

### REDengine（CDPR：巫师3/赛博朋克2077）
| 版本 | 路径 |
|------|------|
| 正版 | `%USERPROFILE%\Documents\CD Projekt Red\<游戏名>\gamesaves\` |
| 破解版 | 同上 |
| 赛博朋克2077 | `%USERPROFILE%\Saved Games\CD Projekt Red\Cyberpunk 2077\` |

### Creation Engine（贝塞斯达：老滚5/辐射4/星空）
| 版本 | 路径 |
|------|------|
| 正版 | `Documents\My Games\<游戏名>\Saves\` |
| 破解版 | 同上；MO2/Vortex 管理器可能用独立存档路径 |

### RAGE（R星：GTA5/大镖客2）
| 版本 | 路径 |
|------|------|
| 正版 | `Documents\Rockstar Games\<游戏名>\Profiles\` |
| 破解版 | 同上，或 `%APPDATA%\<组织名>\`、游戏目录下 |

### Source/GoldSrc（V社：半条命/传送门/求生之路/CS）
| 版本 | 路径 |
|------|------|
| 正版 | `steamapps\common\<游戏>\<游戏>\SAVE\` |
| 破解版 | 同上（存档本来就在游戏目录内） |

### X-Ray（潜行者系列）
| 版本 | 路径 |
|------|------|
| 正版 | `%USERPROFILE%\Documents\Stalker-SHOC\` |
| 破解版 | 同上 |

### Clausewitz（P社：钢铁雄心/群星/十字军之王）
| 版本 | 路径 |
|------|------|
| 正版 | `Documents\Paradox Interactive\<游戏名>\save games\` |
| 破解版 | 同上 |

### Java（Minecraft）
| 版本 | 路径 |
|------|------|
| 正版/破解版 | `%APPDATA%\.minecraft\saves\` |

## 二、图形配置文件

### Unity 引擎
- **位置**：`HKCU\Software\<公司名>\<游戏名>` **注册表**
- **特点**：没有文本文件，全部存注册表，不便手动修改
- **常见项**：`Screenmanager Resolution Width/Height`、`Screenmanager Fullscreen mode`、`UnityGraphicsQuality`

### 虚幻引擎（最规范）
- **位置**：`%LOCALAPPDATA%\<游戏名>\Saved\Config\WindowsNoEditor\`

| 文件 | 内容 |
|------|------|
| `GameUserSettings.ini` | 分辨率、全屏模式、画质档位、帧率限制 |
| `Engine.ini` | 渲染参数、抗锯齿、纹理流送、阴影质量 |
| `Scalability.ini` | 各画质档位的具体参数（视距、后处理等） |

- **特点**：明文 INI 格式，可直接编辑，最方便调整
- 破解版路径基本不变

### RE Engine（卡普空）
- **位置**：游戏根目录 `config.ini` 或 `re_config.ini`
- **特点**：简单键值对，分辨率、窗口模式、刷新率
- 常用项：
```ini
[Render]
MainDisplay=0
DisplayMode=Borderless
Resolution=2560x1440
RefreshRate=144
```

### Source Engine（V社）
- **位置**：`游戏目录\cfg\config.cfg` + `cfg\video.txt`
- **特点**：明文文本，`config.cfg` 包含键位和画质设置
- 修改后进游戏控制台输入 `exec config.cfg` 生效

### RAGE Engine（R星）
- **位置**：`Documents\Rockstar Games\<游戏>\settings.xml`
- **特点**：XML 格式，结构清晰，节点命名直观
- 常见节点：`<Video>`、`<Graphics>`、`<Display>`

### REDengine（CDPR）
- **位置**：`%USERPROFILE%\Documents\CD Projekt Red\<游戏>\UserSettings.json`
- **特点**：JSON 格式，好读好改

### Creation Engine（贝塞斯达）
- **位置**：`Documents\My Games\<游戏名>\` 下的多个 INI 文件
- 核心文件：`SkyrimPrefs.ini` / `Fallout4Prefs.ini` / `StarfieldPrefs.ini`
- **特点**：分层配置，启动器设置写入 `Prefs.ini`，引擎参数写 `Custom.ini`

### X-Ray（潜行者）
- **位置**：`%USERPROFILE%\Documents\Stalker-SHOC\user.ltx`
- **特点**：单个文件包含所有设置，文本可编辑

## 三、破解版通用规律

### 存档便携性
| 情况 | 说明 |
|------|------|
| 好破解 | 把存档路径改到**游戏根目录**内，适合打包整合包 |
| 一般破解 | 照搬正版路径，换电脑要手动拷 |
| 判断方法 | 看游戏目录有没有 `Save\`、`Profile\`、`steam_settings\` 这类文件夹，有的话大概率存这里面 |

### Steam 模拟器痕迹
破解版常通过这些文件模拟 Steam 环境，存档也可能在里面：

- `steam_settings\` 文件夹
- `steam_emu.ini`
- `cream_api.ini`
- `Goldberg SteamEmu Saves\`
- `CODEX\Save\`

### 图形配置不受影响
图形配置文件路径基本不受破解影响，和正版一致——画面的设置不涉及正版验证。

### 找存档的最笨办法
1. 进游戏 → 存档一次 → 退出
2. 用 Everything 搜索最近修改的文件夹
3. 关键词：`Save`、`Profile`、游戏名

## 四、制作整合包建议

做便携整合包时，尽量选存档在游戏目录内的破解版。如果破解版存档在 `AppData` 或 `Documents`，可以考虑：

- 用批处理脚本自动复制 `%APPDATA%` 下的存档到游戏目录
- 查找该游戏有无存档路径重定向工具（如 UE 游戏的 `-SaveDir` 启动参数）
- 在整合包说明文档里写清楚存档位置和迁移步骤
