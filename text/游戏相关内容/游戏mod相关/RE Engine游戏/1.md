# RE Engine Mod 简易安装

1. 安装 REFramework 框架
直接把 dinput8.dll（版本要与游戏匹配）放进游戏根目录（与 exe 同级），然后启动一次游戏，会自动生成 reframework\ 文件夹（含 autorun、plugins 等子目录）；如果没有生成就手动创建。

2. 安装 Mod
下载 Mod 压缩包与前置要求（如果有的话），解压后看包里的目录结构：
- 带 natives\ 或 reframework\ 目录 → 整个合并到游戏根目录（同名目录合并进去）
- Mod 是 .pak 文件 → 改名为 re_chunk_000.pak.patch_0XX.pak 放游戏根目录（XX = 原版补丁链最大编号 + 1，按 012、013… 排下去；编号不能重复、绝不能动原版 patch_001~011）

卸载：删掉自己添加的 patch 文件，或 natives\、reframework\ 目录即可恢复原版。
